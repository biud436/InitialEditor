## v2.0.0-alpha.2

One fix and two developer commands since `v2.0.0-alpha.1`. The engine is unchanged: [Initial2D](https://github.com/biud436/Initial2D) `v2.0.0-alpha.1` (`f04eba2`).

### Fixed

- **Save before run**: the game reads files from disk, so pressing F5 with an unsaved map or script ran the old contents, without any warning. Run (F5), Run from current scene (Ctrl+F5) and Restart now ask first when documents are unsaved: save all and run (Enter), run without saving, or cancel. If a save fails, the game does not start.

### Developer commands

- `yarn test:engine-map`: checks map edits against the real engine. Painted collision blocks the same tiles in the engine, painting a tile in the harbour town and saving still passes the engine's acceptance scenario, and a new map saved as a scene's tilemap renders the same as a reference drawn from the map file. It also runs in the release workflow's Linux installer job.
- `yarn engine:pin <tag>`: binds the pin of the bundled engine to a public engine release, so `yarn engine:fetch` downloads the engine from that release instead of building it.
