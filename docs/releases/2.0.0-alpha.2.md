## v2.0.0-alpha.2

`v2.0.0-alpha.1` 이후의 수정 한 가지와 개발용 명령 두 가지입니다. 엔진은 이전과 같은 [Initial2D](https://github.com/biud436/Initial2D) `v2.0.0-alpha.1`(`f04eba2`)입니다.

### 수정 사항

- **실행 전 저장 확인**: 게임은 디스크의 파일을 읽습니다. 맵이나 스크립트를 수정하고 저장하지 않은 채 F5를 누르면 이전 내용으로 실행되었으며, 별도의 안내도 표시되지 않았습니다.
  이제 실행(F5), 현재 씬부터 실행(Ctrl+F5), 다시 시작을 선택할 때 저장하지 않은 문서가 있으면 먼저 확인합니다: 모두 저장하고 실행(Enter), 저장하지 않고 실행, 취소.
  저장에 실패하면 실행하지 않습니다

### 개발용 명령

- `yarn test:engine-map`: 맵 편집 결과를 실제 엔진과 비교합니다. 통행을 칠하면 엔진에서도 같은 위치가 막히고, 항구 마을에 한 타일을 칠해 저장해도 엔진의 인수 시나리오가
  그대로 통과합니다. 새 맵을 씬의 타일맵으로 저장하면 엔진 화면이 맵 파일로 그린 기준과 일치합니다. 릴리스 워크플로의 Linux 설치본 잡에서도 실행됩니다
- `yarn engine:pin <태그>`: 앱에 포함할 엔진의 핀을 엔진의 공개 릴리스에 연결합니다. 그 뒤 `yarn engine:fetch`는 엔진을 빌드하지 않고 릴리스에서 받습니다
