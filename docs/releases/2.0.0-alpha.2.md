## v2.0.0-alpha.2

`v2.0.0-alpha.1` 뒤의 고침 하나와 검사 둘. 엔진은 그대로 [Initial2D](https://github.com/biud436/Initial2D) `v2.0.0-alpha.1`(`f04eba2`)이다.

### 고친 것

- **실행 전 저장 질문**: 게임은 디스크의 파일을 읽는다. 맵이나 스크립트를 고치고 저장하지 않은 채 F5 를 누르면 옛 내용으로 돌았고 아무것도 알리지 않았다.
  이제 실행(F5), 현재 씬부터 실행(Ctrl+F5), 다시 시작이 저장 안 된 문서가 있으면 먼저 묻는다: 모두 저장하고 실행(Enter), 저장하지 않고 실행, 취소.
  저장에 실패하면 실행하지 않는다

### 검사

- `yarn test:engine-map`: 맵 편집을 진짜 엔진과 견준다. 통행을 칠하면 엔진의 막힘이 같고, 항구 마을에 한 타일을 칠해 저장해도 엔진의 인수 시나리오가
  그대로 통과하고, 새 맵을 씬의 타일맵으로 저장하면 엔진 화면이 맵 파일로 그린 기준과 같다. 릴리스 워크플로의 Linux 설치본 잡에서도 돈다
- `yarn engine:pin <태그>`: 앱에 싣는 엔진의 핀을 엔진의 공개 릴리스에 묶는다. 그 뒤 `yarn engine:fetch` 는 엔진을 빌드하지 않고 릴리스에서 받는다
