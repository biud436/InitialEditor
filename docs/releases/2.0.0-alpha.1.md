## v2.0.0-alpha.1

The first pre-release of the new editor: a Tauri 2 desktop app that also runs in the browser. It ships the [Initial2D](https://github.com/biud436/Initial2D) engine `v2.0.0-alpha.1` (`f04eba2`).

### Features

- **Projects**: open any folder that has a `game.json`, or create a project from a template (empty, Flappy, tilemap). Both Lua and Ruby (mruby) are supported.
- **Scripts**: Monaco editor with engine API completion and signature help, project-wide search, and hot reload into the running game on save.
- **Scenes**: hierarchy, inspector, scene view (grid, snapping, zoom), undo, and script components. Saved scenes open in the engine's scene loader.
- **Maps**: paint with the real tileset (pen, rectangle, fill, eraser, eyedropper), collision, layers, map objects with schema-driven forms, new map and resize, and play from the current map.
- **RPG events** (extension): maps registered in `rpg-game.json` get an event layer. Place events, edit command lists, pick transfer targets on the map, and run the game in front of an event or auto-play it. NPC dialogue and branches need no Lua.
- **Running**: as a separate process with the bundled engine (macOS, Linux), or in the editor's game tab with the web engine. Windows uses the game tab.
- **Android staging**: copies the open project into the engine repository's Android assets folder (requires the engine repository).
- **Browser**: opens local folders through the File System Access API (Chromium-based browsers). Other browsers get an in-memory sample.

### Testing

For every installer, CI launches the app in self-test mode: it creates projects, edits and saves them, runs them with the bundled engine, and judges the results from logs and screenshots. On macOS and Linux, a visible window also compares the Aldebaran forest map view with the game screen, and checks the harbour town event layer and running in front of an event.

### Known limitations

- Not signed or notarized, so the OS blocks the first launch (see "First launch" above).
- The Windows installer has no engine executable, so F5 runs in the game tab (web engine).
- No update check. Download new versions from this page.
- CI cannot test sound or real input.
