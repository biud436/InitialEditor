## v2.0.0-alpha.1

새로 만든 에디터의 첫 프리릴리스다. Tauri 2 데스크톱 앱이고, 같은 앱이 브라우저에서도 돈다. 엔진은
[Initial2D](https://github.com/biud436/Initial2D) `v2.0.0-alpha.1`(`f04eba2`)을 싣는다.

### 되는 것

- **프로젝트**: `game.json` 이 있는 폴더를 열고, 템플릿(빈 프로젝트, 플래피, 타일맵)으로 새 프로젝트를 만든다. Lua 와 Ruby(mruby) 둘 다
- **스크립트**: Monaco 편집기, 엔진 API 자동완성과 시그니처 도움말, 프로젝트 전체 찾기, 저장하면 실행 중인 게임에 핫 리로드
- **씬**: 계층, 인스펙터, 씬 뷰(격자, 스냅, 줌), 되돌리기, 스크립트 컴포넌트. 저장한 씬을 엔진의 씬 로더가 연다
- **맵**: 실제 타일셋으로 칠하기(펜, 사각형, 채우기, 지우개, 스포이드), 통행, 레이어, 맵 오브젝트(스키마 폼), 새 맵과 크기 바꾸기, 이 맵에서 실행
- **RPG 이벤트** (확장): `rpg-game.json` 에 등록된 맵에 이벤트 레이어가 붙는다. 이벤트 배치, 커맨드 목록 편집기, 맵 이동의 대상 선택,
  "이 이벤트 앞에서 실행"과 "이 이벤트 자동 재생". Lua 를 쓰지 않고 NPC 대사와 분기를 만든다
- **실행**: 앱에 든 엔진으로 프로세스 실행(macOS, Linux), 또는 에디터 안 게임 탭(웹 엔진). Windows 는 게임 탭으로 실행한다
- **안드로이드로 스테이징**: 열린 프로젝트를 엔진 저장소의 안드로이드 자산 폴더로 옮긴다 (엔진 저장소가 필요하다)
- **브라우저**: 폴더 열기(File System Access API, Chromium 계열), 없는 브라우저는 메모리 샘플

### 검사

설치본마다 CI 가 앱을 자가 검사 모드로 띄워 새 프로젝트, 편집, 저장, 앱에 든 엔진으로 실행까지 돌리고 로그와 스크린샷으로 판정한다.
macOS 와 Linux 는 보이는 창에서 알데바란 숲의 맵 뷰와 게임 화면 대조, 항구 마을의 이벤트 레이어와 이벤트 앞에서 실행까지 본다.

### 알려진 제약

- 서명과 공증을 하지 않았다. 처음 열 때 운영체제가 막는다 (위의 "처음 열기")
- Windows 설치본에는 엔진 실행 파일이 없어 F5 는 게임 탭(웹 엔진)에서 돈다
- 업데이트 확인은 없다. 새 판은 이 페이지에서 받는다
- 소리와 실제 입력은 CI 가 보지 못한다

자세한 계획과 기록은 [docs/plans/index.md](https://github.com/biud436/InitialEditor/blob/next/docs/plans/index.md) 에 있다.
