## v2.0.0-alpha.1

새로 만든 에디터의 첫 프리릴리스입니다. Tauri 2 데스크톱 앱이며, 브라우저에서도 같은 앱을 실행할 수 있습니다. 엔진은
[Initial2D](https://github.com/biud436/Initial2D) `v2.0.0-alpha.1`(`f04eba2`)을 포함합니다.

### 지원 기능

- **프로젝트**: `game.json`이 있는 폴더를 열고, 템플릿(빈 프로젝트, 플래피, 타일맵)으로 새 프로젝트를 만듭니다. Lua와 Ruby(mruby)를 모두 지원합니다
- **스크립트**: Monaco 편집기, 엔진 API 자동 완성과 시그니처 도움말, 프로젝트 전체 찾기를 지원합니다. 저장하면 실행 중인 게임에 핫 리로드됩니다
- **씬**: 계층, 인스펙터, 씬 뷰(격자, 스냅, 줌), 되돌리기, 스크립트 컴포넌트를 지원합니다. 저장한 씬은 엔진의 씬 로더에서 열립니다
- **맵**: 실제 타일셋으로 칠하기(펜, 사각형, 채우기, 지우개, 스포이드), 통행, 레이어, 맵 오브젝트(스키마 폼), 새 맵 만들기와 크기 변경, 이 맵에서 실행을 지원합니다
- **RPG 이벤트** (확장): `rpg-game.json`에 등록된 맵에 이벤트 레이어가 추가됩니다. 이벤트 배치, 커맨드 목록 편집기, 맵 이동의 대상 선택,
  "이 이벤트 앞에서 실행"과 "이 이벤트 자동 재생"을 지원합니다. Lua를 사용하지 않고 NPC 대사와 분기를 만들 수 있습니다
- **실행**: 앱에 포함된 엔진으로 프로세스를 실행하거나(macOS, Linux), 게임 탭에서 웹 엔진으로 실행합니다. Windows에서는 게임 탭으로 실행합니다
- **안드로이드로 스테이징**: 열린 프로젝트를 엔진 저장소의 안드로이드 자산 폴더로 옮깁니다 (엔진 저장소가 필요합니다)
- **브라우저**: 폴더 열기(File System Access API, Chromium 계열)를 지원합니다. 지원하지 않는 브라우저에서는 메모리 샘플을 사용합니다

### 검사

설치본마다 CI가 앱을 자가 검사 모드로 실행해 새 프로젝트 만들기, 편집, 저장, 앱에 포함된 엔진으로 실행하는 과정까지 확인하고 로그와 스크린샷으로 판정합니다.
macOS와 Linux에서는 화면에 띄운 창에서 알데바란 숲의 맵 뷰와 게임 화면을 대조하고, 항구 마을의 이벤트 레이어와 이벤트 앞에서 실행까지 확인합니다.

### 알려진 제약

- 서명과 공증을 하지 않았습니다. 처음 열 때 운영체제가 차단합니다 (위의 "처음 열기")
- Windows 설치본에는 엔진 실행 파일이 없어 F5는 게임 탭에서 웹 엔진으로 실행됩니다
- 업데이트 확인 기능은 없습니다. 새 버전은 이 페이지에서 받으세요
- CI에서는 소리와 실제 입력을 확인하지 못합니다
