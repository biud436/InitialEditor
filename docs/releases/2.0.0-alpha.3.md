## v2.0.0-alpha.3

Component parameters, script order, a project view filter and reworded Korean UI since `v2.0.0-alpha.2`. The bundled engine is now [Initial2D](https://github.com/biud436/Initial2D) `v2.0.0-alpha.2` (`dcf0aec`), whose scene loaders pass parameters to components.

### New

- **Component parameters**: declare a component's parameters in `scripts/components/<path>.json` (string, text, number, integer, boolean, enum, or a scene object id). The inspector draws a form for each attached component: unset fields show the default, changed values are marked and can be reset, object fields pick an object from the scene. Only changed values are saved, in the scene object's `params`. The scene check reports unknown keys, wrong types, values out of range and ids that are not in the scene. A component without a declaration can get one from its current values in one click, and declaration files are checked against a schema in the editor, with violations shown as errors. Lua components receive the values as the last hook argument, Ruby components in `initialize(params = {})`. Renaming an object updates the parameters that point at it.
- **Older projects**: each project keeps its own copy of the scene loader. When that copy predates parameters, the inspector says so and can replace it with the bundled loader after a confirmation.
- **Script order**: the inspector numbers a scene object's scripts in the order the engine calls them, with buttons to move one up or down (one undo step).
- **Korean UI wording**: the editor's Korean was rewritten to read naturally. Labels, buttons and states stay short, while notices, dialogs, errors and tooltips are now full sentences in the polite form instead of clipped noun endings. A few terms changed as well (for example "version" and "editor" now use the common words).
- **Project view filter**: the project tree shows `game.json`, `scripts/` and `resources/` and hides dot folders and what `.initial-editorignore` lists (the same syntax as `.gitignore`). A toolbar button shows everything and tells how many files are hidden. Project search, game tab staging and the inspector's file lists follow the same rules.

### Developer commands

- `yarn test:engine-scene` also writes a parameter declaration and values through the editor's scene model and checks what the real engine hands the component, in Lua and Ruby.
