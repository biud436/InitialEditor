# E2: 씬과 오브젝트

**권장 모델**: Claude Fable 5. 씬 포맷은 두 저장소가 공유하는 데이터 계약이고, 씬 뷰의 편집 상태(선택, 끌기, 스냅, 되돌리기)는
상태 관리 버그가 숨기 쉬운 영역이다.

> 목표: **씬에 오브젝트를 놓고 속성을 고치고 저장하면 게임이 그 씬을 연다.** 증명은 플래피버드다.
> 엔진의 `flappy.lua`를 씬 하나와 컴포넌트 둘로 다시 만들어 에디터에서 열고 고치고 실행한다.

## 선행 조건

- E0 완료. E1은 없어도 되지만 있으면 F5로 바로 확인할 수 있다.
- **R1(엔진 씬 로더)과 함께 진행한다.** 포맷은 두 저장소가 같은 픽스처를 보며 정한다.

## 구현 노트 (2026-09-26)

- **계약은 엔진이 정본이다.** 씬 포맷 v1 의 정본은 엔진 `docs/plans/r1-scene-loader.md` 이고, 코어의 `scene.ts` 는 그 목록(버전, 모르는 키 보존, 유일한 id, 등록된 타입, `/` 상대 경로, 그리기 순서, 논리 스크립트 이름)을 그대로 검사한다. 엔진이 더한 것 하나(`frameDelay`)는 코어 기본값에도 넣었다. 글자의 `color` 는 엔진이 적용하지 않으므로 인스펙터에 안내만 둔다.
- **되돌리기 한 단계의 단위.** 씬 뷰의 끌기는 드래그마다 `coalesceKey` 하나로 `moveObjects` 를 합치고, 인스펙터의 타이핑은 초점 세션마다 키를 만든다. 여러 오브젝트에 걸친 삭제나 붙여넣기는 `compoundCommand` 로 한 단계다.
- **씬 뷰는 근사다.** PIXI 8 이 그리는 스프라이트는 첫 프레임 한 장이고 글자는 시스템 글꼴(엔진은 BMFont)이다. 상태 띠의 "근사" 배지에 적어 두었고 진짜 화면은 실행(F5, 현재 씬부터 실행 Ctrl+F5)이 보여 준다. 헤드리스 Chromium 의 WebGL 로 e2e 가 돈다.
- **열기 경로는 감싸기의 사슬이다.** E1 의 스크립트 지원이 `editor.openPath` 를 감싸고 그 바깥을 씬 지원이 감싸 `resources/scenes/*.json` 을 먼저 가로챈다. 코어에 열기 레지스트리를 두는 것이 정리 항목으로 남아 있다.
- **템플릿은 엔진 저장소의 사본이다.** `yarn sync:templates`(`INITIAL2D_DIR`)가 씬 로더, 타일맵 타입 모듈, 진입 파일, 빈 씬, 플래피 씬과 컴포넌트와 자산, 한글 폰트, API 명세를 `packages/app/templates/` 로 복사하고 `MANIFEST.json`(sha256)을 남긴다. 단위 테스트가 엔진 저장소가 있을 때 원본과 대조한다. 새 프로젝트는 그 목록대로 쓴다.
- **교차 검사.** `yarn test:engine-scene` 이 빈 프로젝트와 플래피를 Lua 와 Ruby 로 임시 폴더에 쓰고 진짜 엔진을 헤드리스로 돌려 종료 코드, 오류 줄, 스크린샷, 컴포넌트 로그, 플래피 상태 전이를 본다 (26건). "에디터가 만든 것이 게임에서 돈다" 를 사람이 아니라 스크립트가 확인한다.
- **Tauri 네이티브 메뉴의 복사와 붙여넣기.** `nativeMenu.ts` 가 편집의 잘라내기와 복사와 붙여넣기를 OS 항목으로 바꿔 두어, Tauri 모드에서는 씬 탭이 활성이어도 웹뷰의 글자 복사가 된다. 씬 오브젝트 복사는 브라우저 메뉴와 단축키 처리에서만 된다. E3 에서 씬 탭이 활성이면 우리 커맨드를 쓰게 고친다.
