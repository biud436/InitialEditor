# E2: 씬과 오브젝트

**권장 모델**: Claude Fable 5. 씬 포맷은 두 저장소가 공유하는 데이터 계약이고, 씬 뷰의 편집 상태(선택, 끌기, 스냅, 되돌리기)는
상태 관리 버그가 숨기 쉬운 영역이다.

> 목표: **씬에 오브젝트를 놓고 속성을 고치고 저장하면 게임이 그 씬을 연다.** 증명은 플래피버드다.
> 엔진의 `flappy.lua`를 씬 하나와 컴포넌트 둘로 다시 만들어 에디터에서 열고 고치고 실행한다.

## 선행 조건

- E0 완료. E1은 없어도 되지만 있으면 F5로 바로 확인할 수 있다.
- **R1(엔진 씬 로더)과 함께 진행한다.** 포맷은 두 저장소가 같은 픽스처를 보며 정한다.

## 작업 항목

### 마일스톤 1: 포맷과 픽스처

- [ ] 씬 포맷 v1 확정 ([03-project-and-runtime.md](03-project-and-runtime.md) 5절 초안에서). 코어 타입 `node`, `sprite`, `text`의 `props` 목록
- [ ] 픽스처 `sample_v1.json`을 엔진 저장소 `tests/fixtures/scenes/`에 두고 이 저장소에 사본. 줄바꿈과 한글이 든 `text`, 모르는 키(`"editorOnly": {...}`) 하나를 넣는다
- [ ] `core`의 `SceneFormat`: 읽기, 검증(버전, id 중복, 모르는 타입), 쓰기(키 순서 고정, 보존 키). `node --test`로 왕복

### 마일스톤 2: 계층 패널

- [ ] 오브젝트 트리, 선택 동기화(계층과 씬 뷰가 같은 선택을 본다), 끌어서 순서 바꾸기(그리기 순서), 이름 바꾸기, 삭제와 복제
- [ ] "오브젝트 추가" 메뉴: 코어 타입과 확장이 등록한 타입

### 마일스톤 3: 인스펙터

- [ ] 공통 속성: id, x, y, 표시 여부, 투명도. 회전과 배율은 스프라이트에만 (엔진 Sprite가 지원하는 것만 노출한다)
- [ ] `sprite`: 이미지 파일 고르기(프로젝트 패널 연동), 프레임 수와 프레임 크기, 미리보기
- [ ] `text`: 글, 폰트 파일(BMFont `.fnt`), 색
- [ ] 스크립트 컴포넌트 목록: 추가(파일 고르기나 새로 만들기), 제거, 편집기로 열기
- [ ] 입력은 명령 객체(`SetPropertyCommand`)를 거쳐 되돌리기에 들어간다. 드래그 중 연속 변경은 하나로 합친다

### 마일스톤 4: 씬 뷰 (PIXI 8)

- [ ] 격자(`game.json`의 논리 해상도와 `renderScale`을 반영), 줌과 팬, 카메라 사각형
- [ ] 선택: 클릭, Shift 추가, 상자 선택. 선택 상자와 핸들
- [ ] 이동: 끌기, 방향키(1px, Shift로 10px), 스냅(격자 크기 설정)
- [ ] 타입별 렌더링은 `createSceneNode`가 준 PIXI 노드. `sprite`는 첫 프레임, `text`는 BMFont 렌더(PIXI의 BitmapText), `node`는 십자 표시
- [ ] 테마 색 연동(배경, 격자, 선택)
- [ ] 문서가 바뀌면 씬 뷰가 따라오고, 씬 뷰에서 바꾸면 명령으로 문서가 바뀐다. 한 방향씩

### 마일스톤 5: 명령과 되돌리기

- [ ] `AddObject`, `RemoveObject`, `MoveObjects`, `SetProperty`, `Reorder`, `AttachScript`, `DetachScript`
- [ ] 스택 20단계 뒤 되돌리기 20번이 원래 파일과 동등(단위 테스트)

### 마일스톤 6: 템플릿과 예제 (엔진 저장소와 함께)

- [ ] 빈 프로젝트 템플릿: 씬 하나, `main.lua`와 `main.rb`가 씬 로더로 시작 씬을 연다, `game.json`
- [ ] **플래피버드를 씬으로**: 엔진 저장소에 `scripts/lua/games/flappy_scene/`(씬 파일, 새 컴포넌트, 파이프 스포너 컴포넌트)를 만들고, 기존 `flappy.lua`의 자동 시연 인수와 같은 검사를 통과시킨다. Ruby 판도. 에디터 템플릿은 그 폴더를 복사한다
- [ ] "새 프로젝트" 대화상자에서 템플릿을 고른다

### 마일스톤 7: 교차 인수

- [ ] `core`가 Node에서 만든 씬 파일을 엔진이 헤드리스로 열어 골든과 대조하는 테스트를 엔진 저장소에 둔다 (`scene_loader_scene`). 이 저장소 CI가 엔진 저장소를 체크아웃해 돌린다
- [ ] Playwright(브라우저 모드): 오브젝트 추가, 끌기, 속성 수정, 저장 뒤 파일 내용이 기대와 같다

## 완료 기준

- [ ] 빈 씬에 스프라이트 둘과 글자 하나를 놓고 저장하면 엔진이 같은 자리에 그린다 (골든)
- [ ] 플래피버드 템플릿으로 만든 프로젝트가 에디터에서 열리고 F5로 돌며, 엔진 저장소의 자동 시연 인수가 통과한다
- [ ] 픽스처 왕복이 양쪽에서 통과하고, 모르는 키가 보존된다
- [ ] 되돌리기 20단계 뒤 파일이 동등하다
- [ ] 씬 뷰에서 옮긴 위치와 게임 화면의 위치가 픽셀 단위로 같다 (근사의 허용 범위를 여기서 처음 잰다)
- [ ] 두 저장소의 README에 사용법이 있다
