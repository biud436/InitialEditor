# 용어

이 설명서에서 쓰는 용어의 정의입니다.

| 용어 | 정의 |
|---|---|
| 프로젝트 | `game.json` 파일이 있는 폴더입니다. 엔진은 이 폴더를 작업 디렉터리로 삼아 실행되고, 모든 경로는 이 폴더를 기준으로 합니다 |
| `game.json` | 프로젝트 설정 파일입니다. 창 크기, 렌더 배율, 스크립트 언어, 시작 씬을 담습니다 |
| 엔진 | 프로젝트를 읽어 게임을 실행하는 프로그램(Initial2D)입니다. 데스크톱용 실행 파일과 브라우저용 WebAssembly 빌드가 있습니다 |
| 틱 | 게임 상태를 갱신하는 단위입니다. 엔진은 16ms 간격(초당 약 60회)으로 틱을 실행하고, 매 틱마다 스크립트의 `update`를 호출합니다 |
| 프레임 | 화면을 한 번 그리는 단위입니다. 프레임마다 스크립트의 `render`가 호출됩니다. 한 프레임 사이에 틱이 0번 이상 실행됩니다 |
| 씬 | 한 화면을 구성하는 오브젝트 목록을 담은 JSON 파일(`resources/scenes/<이름>.json`)입니다. 실행 중에는 씬 로더 스크립트가 이 파일을 읽어 오브젝트를 만듭니다 |
| 씬 로더 | 씬 파일을 읽고 검사해 오브젝트와 컴포넌트를 만드는 스크립트(`scripts/lua/scene_loader.lua`, `scripts/ruby/scene_loader.rb`)입니다. 새 프로젝트에 함께 복사됩니다 |
| 오브젝트 | 씬에 들어 있는 항목 하나입니다. id, 종류(빈 노드, 스프라이트, 텍스트, 타일맵), 위치, 표시 여부, 속성, 컴포넌트 목록을 가집니다 |
| 스프라이트 | 이미지 파일의 일부 또는 전체를 화면에 그리는 오브젝트입니다 |
| 컴포넌트 | 오브젝트에 연결하는 스크립트 모듈입니다. 엔진이 정해진 시점에 컴포넌트의 함수(`init`, `update`, `render`, `destroy`)를 호출합니다 |
| 논리 이름 | 컴포넌트를 가리키는 언어 공통 이름입니다. `components/player`는 Lua에서 `scripts/lua/components/player.lua`, Ruby에서 `scripts/ruby/components/player.rb`를 뜻합니다 |
| 매개변수 | 같은 컴포넌트를 쓰는 오브젝트마다 다르게 지정하는 값입니다. 선언 파일(`scripts/components/<논리 이름>.json`)에 항목을 정의하고, 값은 씬 파일에 저장합니다 |
| 맵 | 타일 배치, 통행 정보, 맵 오브젝트를 담은 JSON 파일(`resources/maps/<이름>.json`)입니다 |
| 타일셋 | 같은 크기의 타일 이미지를 격자로 배열한 PNG 파일입니다 |
| 레이어 | 맵에서 타일을 배치하는 층입니다. 여러 레이어를 순서대로 겹쳐 그립니다 |
| 맵 오브젝트 | 맵 파일의 `objects`에 저장되는 항목(몬스터, 시작 지점 등)입니다. 종류와 속성은 프로젝트의 스키마 파일이 정의합니다 |
| 이벤트 | RPG 프로젝트에서 맵 파일의 `events`에 저장되는 항목입니다. 트리거 조건과 실행할 커맨드 목록을 가집니다 |
| 그래프 | 노드와 연결선으로 컴포넌트를 정의한 파일(`*.graph.json`)입니다. 저장하면 같은 동작의 Lua와 Ruby 코드가 생성됩니다 |
| 핫 리로드 | 게임 실행 중에 바뀐 스크립트 파일을 엔진에 보내고 스크립트 실행 환경을 다시 시작하는 기능입니다 |
| 논리 좌표 | 게임 화면의 좌표입니다. 원점은 화면 왼쪽 위이고 x는 오른쪽, y는 아래쪽으로 증가합니다. 단위는 픽셀이며 크기는 창 크기를 렌더 배율로 나눈 값입니다 |
