# 단축키

Mac에서는 Ctrl 대신 Cmd(⌘), Alt 대신 Option(⌥)을 누르세요. 메뉴에는 쓰고 있는 운영체제에 맞게 표시됩니다.

스크립트 편집기나 입력란에서 글을 입력하는 중에는 파일, 실행, 되돌리기, 다시 실행 단축키만 에디터가 처리합니다. 나머지 키는 입력하던 곳에서 그대로 동작합니다.

## 파일

| 기능 | 단축키 |
|---|---|
| 새 프로젝트 | Ctrl+N |
| 프로젝트 열기 | Ctrl+O |
| 저장 | Ctrl+S |
| 모두 저장 | Ctrl+Shift+S |
| 새 스크립트 | Ctrl+Alt+N |
| 새 그래프 컴포넌트 | Ctrl+Alt+G |
| 새 씬 | Ctrl+Shift+N |
| 새 맵 | Ctrl+Alt+M |

## 편집

| 기능 | 단축키 |
|---|---|
| 되돌리기 | Ctrl+Z |
| 다시 실행 | Ctrl+Shift+Z |
| 잘라내기, 복사, 붙여넣기 | Ctrl+X, Ctrl+C, Ctrl+V |
| 복제 | Ctrl+D |
| 삭제 | Delete |
| 찾기 | Ctrl+F |
| 프로젝트에서 찾기 | Ctrl+Shift+F |

## 실행

| 기능 | 단축키 |
|---|---|
| 실행 | F5 |
| 정지 | Shift+F5 |
| 현재 씬부터 실행, 이 맵에서 실행 | Ctrl+F5 |
| 리로드 | Ctrl+Shift+R |

## 씬 뷰

| 기능 | 단축키 |
|---|---|
| 오브젝트 추가 | Ctrl+Shift+A |
| 확대, 축소, 100% | Ctrl+=, Ctrl+-, Ctrl+0 |
| 선택한 오브젝트 이동 | 방향키 (Shift를 누르면 10px씩) |
| 선택 해제 | Esc |
| 화면 이동 | Space를 누른 채 드래그 |
| 계층에서 이름 바꾸기 | F2 |

## 맵 뷰

| 기능 | 단축키 |
|---|---|
| 펜, 사각형, 채우기 | B, R, G |
| 지우개, 스포이드 | E, I |
| 통행, 오브젝트 | C, V |
| 이벤트 도구 (RPG 프로젝트) | N |
| 확대, 축소, 100% | Ctrl+=, Ctrl+-, Ctrl+0 |
| 화면 이동 | Space를 누른 채 드래그, Shift+휠 |

## 스크립트 편집기

| 기능 | 단축키 |
|---|---|
| 자동 완성 열기 | Ctrl+Space (macOS도 Ctrl+Space) |
| 정의로 이동 | F12, Ctrl+클릭 |
| 참조 찾기 | Shift+F12 |
| 이름 바꾸기 | F2 |
| 기호로 이동 | Ctrl+Shift+O |
| 줄 주석 | Ctrl+/ |
| 편집기 명령 목록 | F1 |

## 그래프 편집기

| 기능 | 단축키 |
|---|---|
| 화면 맞춤 | F |
| 화면 이동 | Space를 누른 채 드래그 |
| 연결 끊기 | Alt+포트 클릭 |

## 도움말과 설정

| 기능 | 단축키 |
|---|---|
| 사용자 가이드 | F1 (스크립트 편집기가 아닌 곳에서) |
| 설정 | Ctrl+, |
