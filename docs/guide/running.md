# 게임 실행

![게임 탭](images/game-tab.png)

## 실행과 정지

| 조작 | 단축키 |
|---|---|
| 실행 | F5 |
| 정지 | Shift+F5 |
| 현재 씬부터 실행 (맵 탭에서는 이 맵에서 실행) | Ctrl+F5 |
| 다시 시작 | 실행 > 다시 시작 |
| 리로드 (게임 창을 두고 스크립트만 다시 불러오기) | Ctrl+Shift+R |

저장하지 않은 문서가 있으면 실행 전에 묻습니다. 게임은 디스크의 파일을 읽으므로 저장해야 바뀐 내용이 보입니다. Enter를 누르면 모두 저장하고 실행합니다.

실행할 언어는 `game.json`의 `script`이고, 도구 모음의 언어 목록이나 **실행 > 언어**에서 바꿉니다.

## 두 가지 실행 방식

**도구 > 설정**의 **실행 방식**에서 정합니다.

| 방식 | 화면 | 특징 |
|---|---|---|
| 프로세스 (기본) | 별도 창 | 엔진 실행 파일을 그대로 실행합니다. 배포할 게임과 똑같이 동작합니다 |
| 게임 탭 | 에디터 안의 탭 | 엔진의 웹 빌드를 에디터 안에서 실행합니다. 스크립트를 보면서 나란히 확인하기 좋습니다 |

웹판과 Windows 판은 항상 게임 탭에서 실행됩니다. 엔진 실행 파일을 찾지 못한 경우에도 게임 탭으로 실행됩니다.

### 게임 탭 사용법

- 게임 탭은 처음에 문서 영역 오른쪽에 열립니다. 다른 자리로 끌어 두면 다음에도 그 자리에 열립니다.
- 게임 화면을 누르면 키보드 입력이 게임으로 갑니다. F5, Shift+F5 같은 실행 단축키는 게임에 입력이 가 있어도 에디터가 받습니다.
- 브라우저 정책상 처음에는 소리가 나지 않습니다. 위쪽의 **소리 켜기**를 누르거나 게임 화면을 한 번 누릅니다.
- 위쪽 띠에 실행 상태, 화면 크기와 배율, FPS가 표시됩니다.

## 저장하면 바로 반영 (핫 리로드)

게임이 실행 중일 때 스크립트, 씬, 맵을 저장하면 게임 창을 닫지 않고 바뀐 파일을 다시 불러옵니다. 콘솔에 "핫 리로드" 줄이 남습니다. 스크립트를 처음부터 다시 불러오므로 점수 같은 진행 상태는 처음으로 돌아갑니다.

끄려면 **도구 > 설정**의 **저장 시 리로드**를 해제합니다.

## 콘솔과 오류

게임의 `print` 출력과 엔진 로그는 콘솔에 표시됩니다. 스크립트 오류는 이런 줄로 나옵니다.

```
Lua error in update: ./scripts/lua/components/player.lua:12: attempt to index a nil value
```

파일과 줄 번호 부분은 링크입니다. 누르면 그 스크립트의 그 줄로 이동합니다. 그래프로 만든 컴포넌트에서 난 오류는 그래프가 열리고 그 줄을 만든 노드가 선택됩니다.

- 게임 시작 중이나 `update`, `render`에서 오류가 나면 게임이 종료 코드 1로 끝납니다. 오류를 수정하고 F5로 다시 실행합니다.
- 실행 중에 저장한 스크립트에 오류가 있으면 게임은 닫히지 않고 스크립트만 멈춥니다. 수정해서 다시 저장하면 이어서 실행됩니다.

## 엔진 찾기 (데스크톱 앱)

프로세스 방식은 엔진 실행 파일을 다음 순서로 찾습니다.

1. **도구 > 설정**의 **엔진 경로** (또는 **실행 > 엔진 경로**)
2. 프로젝트의 `.initial-editor/engine` 파일에 적힌 경로
3. 프로젝트 안의 `build/Initial2D`
4. 앱에 들어 있는 엔진
5. 프로젝트 옆 폴더의 `../Initial2D/build/Initial2D`

2, 3, 5번처럼 프로젝트가 가리키는 실행 파일은 처음 한 번 경로를 보여 주고 실행해도 되는지 묻습니다. 받은 프로젝트에 든 실행 파일이 확인 없이 실행되지 않게 하기 위해서입니다. 허용 여부는 **도구 > 설정**의 **찾은 엔진** 줄에서 취소할 수 있습니다.

지금 쓰는 엔진은 상태 바와 **도움말 > InitialEditor 정보**에 표시됩니다.

## 안드로이드 기기에서 실행

**실행 > 안드로이드로 스테이징**은 열린 프로젝트를 엔진 저장소의 안드로이드 프로젝트로 복사합니다. APK 빌드와 설치는 하지 않고, 끝나면 이어서 입력할 명령을 콘솔에 적어 줍니다.

- 엔진 저장소(Initial2D 소스)와 bash, python3이 필요합니다. Windows는 Git for Windows의 bash가 필요합니다.
- 엔진 저장소 위치는 **도구 > 설정**의 **엔진 저장소**에서 정합니다. 비우면 자동으로 찾습니다.
- 확인 창에서 복사할 파일 수와 크기를 먼저 보여 줍니다.
