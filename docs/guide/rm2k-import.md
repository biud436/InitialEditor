# RPG Maker 2000 게임 가져오기 따라 하기

맵 가져오기는 RPG Maker 2000으로 만든 게임의 맵을 이 에디터의 맵 파일로 옮기는 기능입니다. 타일, 두 레이어(하층과 상층), ChipSet의 통행 설정, 물결 설정을 옮기고, ChipSet 이미지를 프로젝트에 복사합니다. 가져온 맵은 [RPG Maker 2000 맵 따라 만들기](rm2k-tutorial.md)에서 만든 맵과 같은 형식이라, 같은 팔레트와 오토타일로 이어서 고칠 수 있습니다.

이 문서는 게임 폴더를 고르는 것부터 가져온 맵을 게임 창에 띄우는 것까지 순서대로 설명합니다. 옮기는 규칙(타일 번호, 통행, 레이어)은 [RPG Maker 2000 ChipSet](rm2k.md#rpg-maker-2000-게임-가져오기)에 있습니다.

## 준비

| 준비물 | 설명 |
|---|---|
| 프로젝트 | **타일맵** 템플릿으로 만든 프로젝트. 만드는 방법은 [첫 프로젝트](first-project.md)에 있습니다 |
| 게임 폴더 | RPG Maker 2000의 프로젝트 폴더. `RPG_RT.ldb`(데이터베이스), `RPG_RT.lmt`(맵 트리), `Map0001.lmu` 같은 맵 파일, `ChipSet` 폴더가 들어 있습니다 |

게임 폴더에는 음악과 캐릭터 이미지도 들어 있지만, 맵 가져오기는 데이터베이스, 맵 트리, 맵 파일, ChipSet 이미지만 읽습니다.

> **주의**: RTP(기본 제공 소재)를 쓰는 게임은 게임 폴더의 `ChipSet` 폴더에 이미지가 없습니다. 가져오기 전에 그 게임이 쓰는 ChipSet 이미지를 RTP 폴더에서 프로젝트의 `resources/ChipSet`으로 복사합니다. 파일 이름은 그대로 둡니다 (예: `resources/ChipSet/Exterior.png`). RTP 소재는 정품 보유자만 쓸 수 있고 따로 배포할 수 없습니다.

## 1. 맵 가져오기 대화상자 열기

**맵 > 맵 가져오기**를 선택합니다. 대화상자의 **형식**에 `RPG Maker 2000 게임`이 표시됩니다. 프로젝트가 열려 있지 않으면 이 메뉴는 꺼져 있습니다.

## 2. 게임 폴더 선택

1. **폴더 선택**을 누릅니다.
2. `RPG_RT.ldb`가 든 게임 폴더를 선택합니다. 그 폴더를 담은 위 폴더를 선택해도 됩니다. 에디터는 `RPG_RT.ldb`가 가장 얕은 곳에 있는 폴더를 게임 폴더로 봅니다.

웹판과 브라우저 모드에서는 폴더를 고를 때 브라우저가 파일을 이 사이트에 업로드할지 묻습니다. 파일은 서버로 보내지 않고 에디터 안에서만 읽으므로 **업로드**를 눌러 진행합니다.

폴더 이름 옆에 고른 폴더의 파일 수가 표시되고, 그 아래에 게임 이름과 맵 목록이 나타납니다.

## 3. 맵 목록 확인

맵 목록의 한 줄이 맵 파일 하나(`Map0001.lmu` 따위)입니다. 각 줄은 다음 내용을 보입니다.

| 항목 | 예 | 뜻 |
|---|---|---|
| 이름 | `MAP0001 시작의 마을` | 맵 번호와 RPG Maker 2000 맵 트리의 이름 |
| 크기와 ChipSet | `20x15, ChipSet Exterior` | 맵의 크기(타일)와 데이터베이스에서 이 맵이 쓰는 ChipSet 이미지 |
| 쓸 파일 | `resources/maps/map0001.json` | 가져오면 만들 맵 파일 |
| 빨간 글 | `ChipSet 이미지가 없습니다: Exterior` | 가져올 수 없는 이유. 이 맵은 선택할 수 없습니다 |
| 회색 글 | `이벤트 22개는 가져오지 않습니다` | 가져오되 옮기지 않는 내용 |

처음에는 가져올 수 있고 프로젝트에 같은 파일이 없는 맵이 모두 선택되어 있습니다. 목록 위의 체크 상자는 가져올 수 있는 맵 전체를 선택하거나 해제합니다.

맵 이름은 게임을 만든 컴퓨터의 문자 인코딩으로 저장되어 있습니다. 에디터가 인코딩을 자동으로 고르고, 고른 인코딩을 게임 이름 옆에 표시합니다 (예: `자동으로 선택한 텍스트 인코딩: 한국어 (CP949)`). 이름이 깨져 보이면 **텍스트 인코딩**에서 게임에 맞는 인코딩을 고릅니다. 목록을 다시 읽고, 선택한 맵은 그대로 둡니다.

## 4. 가져오기

**맵 N개 가져오기**를 누릅니다. 대화상자 아래에 진행 상황이 표시되고, 끝나면 대화상자가 닫히고 첫 맵이 열립니다. 에디터가 만드는 파일은 다음과 같습니다.

| 파일 | 내용 |
|---|---|
| `resources/maps/map0001.json` | 맵 하나. 파일 이름은 RPG Maker 2000의 맵 번호입니다. 맵 이름은 파일의 `name`에 들어갑니다 |
| `resources/ChipSet/<이름>.png` | 게임 폴더의 ChipSet 이미지. BMP와 XYZ는 PNG로 바꿔 씁니다 |
| `resources/tiles/<이름>.rm2k.png` | ChipSet으로 만든 아틀라스. 엔진은 이 이미지로 맵을 그립니다 |

**콘솔** 패널에 맵마다 한 줄씩 결과가 남습니다. 만든 레이어, 지나갈 수 없는 타일 수, 옮기지 않은 내용이 적혀 있습니다.

## 5. 가져온 맵 살펴보기

가져온 맵은 RPG Maker 2000에서 보던 것과 같은 타일로 그려지고, 물과 애니메이션 타일이 게임과 같은 간격으로 움직입니다.

**레이어** 패널에는 다음 레이어가 있습니다.

| 레이어 | 내용 |
|---|---|
| `lower` | 하층 타일 |
| `upper` | 상층 타일 |
| `lower_over` | ChipSet 설정에서 별(캐릭터 위에 표시)이나 벽이 지정된 하층 타일. 해당 타일이 있는 맵에만 생깁니다 |
| `upper_over` | 별이 지정된 상층 타일. 해당 타일이 있는 맵에만 생깁니다 |

RPG Maker 2000은 별이 지정된 타일을 캐릭터 위에 그립니다. 이 순서를 지키도록 그런 타일을 뒤쪽 레이어로 옮깁니다.

맵 뷰 위쪽의 **통행** 버튼을 누르면 지나갈 수 없는 타일이 붉게 표시됩니다. 통행은 ChipSet의 통행 설정에서 정해집니다. 네 방향 모두 막힌 타일만 지나갈 수 없는 타일이 되고, 한두 방향만 막힌 타일(절벽 끝 따위)은 지나갈 수 있는 타일이 됩니다. 필요하면 **통행**(C) 도구로 고칩니다.

팔레트는 ChipSet의 하층과 상층 두 쪽이고, 칠하면 오토타일의 모양이 이웃에 맞춰집니다. 칠하는 방법은 [RPG Maker 2000 맵 따라 만들기](rm2k-tutorial.md)의 4단계와 5단계에 있습니다.

## 6. 게임에서 보기

타일맵 템플릿의 시작 씬 `resources/scenes/main.json`에는 맵을 그리는 오브젝트 `map`이 있습니다.

1. **프로젝트** 패널에서 `resources/scenes/main.json`을 엽니다.
2. **계층** 패널에서 `map`을 선택합니다.
3. 인스펙터에서 다음 값을 지정합니다.

| 항목 | 값 | 뜻 |
|---|---|---|
| 맵 파일 | `resources/maps/map0001.json` | 그릴 맵 |
| 오브젝트 아래 레이어 수 | 2 | `lower`와 `upper`는 씬의 다른 오브젝트 아래에, `lower_over`와 `upper_over`는 위에 그립니다 |

4. **Ctrl+S**로 저장하고 **F5**로 실행합니다.

게임 창의 왼쪽 위에 맵이 그려집니다. RPG Maker 2000과 같은 화면 크기로 보려면 `game.json`의 `windowWidth`를 640, `windowHeight`를 480, `renderScale`을 2로 바꿉니다. 화면보다 큰 맵은 왼쪽 위의 320x240 부분만 보입니다.

## 7. 다시 가져오기

RPG Maker 2000에서 맵을 고친 뒤 같은 게임 폴더를 다시 가져오면, 프로젝트에 이미 있는 맵은 선택되지 않은 채로 목록에 나옵니다. 그 맵을 선택하면 줄에 `이미 있는 파일을 덮어씁니다`가 표시되고, 가져오면 맵 파일을 새로 씁니다.

> **주의**: 덮어쓰면 이 에디터에서 그 맵에 한 편집(칠한 타일, 통행, 맵 오브젝트)이 사라집니다. 되돌리기로도 돌아오지 않습니다.

ChipSet 이미지가 프로젝트의 것과 다르면 게임 폴더의 이미지로 바꾸고 콘솔에 남깁니다. 아틀라스는 가져올 때마다 다시 만듭니다.

## 가져오지 않는 것

| 내용 | 대신 할 일 |
|---|---|
| 이벤트(캐릭터, 대화, 순간 이동) | 맵 목록에 개수가 표시됩니다. 이벤트는 [RPG 이벤트](rpg-events.md)로 다시 만듭니다 |
| 원경(파노라마) 이미지 | 씬에 이미지 오브젝트를 둡니다 |
| 맵의 배경 음악, 인카운트, 맵 트리의 계층 | 씬과 스크립트로 정합니다 |
| 방향별 통행, 카운터, 지형 번호, 탈것의 통행 | 엔진의 통행은 지나갈 수 있음과 없음 두 가지입니다 |
| 이벤트로 바꾼 타일(타일 치환) | 맵에 칠한 타일이 그대로 들어옵니다 |

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| **맵 가져오기** 메뉴가 꺼져 있습니다 | 프로젝트가 열려 있지 않습니다. 프로젝트를 먼저 엽니다 |
| `RPG Maker 2000 게임 폴더가 아닙니다`가 표시됩니다 | 고른 폴더와 그 아래에 `RPG_RT.ldb`가 없습니다. `RPG_RT.ldb`가 든 폴더를 고릅니다 |
| `ChipSet 이미지가 없습니다: <이름>`이 표시됩니다 | 게임 폴더의 `ChipSet`에도, 프로젝트의 `resources/ChipSet`에도 그 이미지가 없습니다. RTP를 쓰는 게임이면 RTP의 이미지를 `resources/ChipSet/<이름>.png`로 복사하고 폴더를 다시 선택합니다 |
| `ChipSet 이미지를 읽지 못했습니다`가 표시됩니다 | 이미지가 480x256이 아니거나 압축한 BMP입니다. 이미지 편집기에서 PNG로 저장해 게임 폴더의 `ChipSet`에 두고 다시 선택합니다 |
| 맵 이름이 깨져 보입니다 | 텍스트 인코딩이 다릅니다. **텍스트 인코딩**에서 게임에 맞는 인코딩을 고릅니다. 맵 파일과 타일은 인코딩과 상관없이 같습니다 |
| 나무 윗부분이 캐릭터 아래에 그려집니다 | 씬의 **오브젝트 아래 레이어 수**가 레이어 수와 같습니다. 2로 바꿉니다 |
| 한쪽에서만 지나가야 할 타일을 어느 쪽에서나 지나갑니다 | 방향별 통행은 가져오지 않습니다. **통행**(C) 도구로 막을 타일을 칠합니다 |
| 게임에서 물이 움직이지 않습니다 | [RPG Maker 2000 맵 따라 만들기](rm2k-tutorial.md)의 6단계 주의를 확인합니다 |

다음으로 읽을 문서: [RPG Maker 2000 ChipSet](rm2k.md)(옮기는 규칙, 오토타일, 맵 파일의 타일셋 항목), [맵](maps.md)(레이어, 통행, 맵 오브젝트).
