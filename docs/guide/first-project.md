# 첫 프로젝트

템플릿으로 프로젝트를 만들어 실행하고, 값을 하나 바꿔 보는 데까지 따라가 봅니다. 예제로는 플래피버드 템플릿을 씁니다.

## 1. 새 프로젝트 만들기

1. 시작 화면에서 **새 프로젝트**를 누르거나, **파일 > 새 프로젝트**(Ctrl+N)를 선택합니다.
2. 프로젝트를 저장할 폴더를 고릅니다. 빈 폴더를 권합니다. 파일이 이미 있는 폴더를 고르면, 있던 파일은 그대로 두고 없는 파일만 만들겠다는 확인 창이 뜹니다.
3. 이름, 템플릿, 언어를 정하고 **만들기**를 누릅니다.

| 항목 | 설명 |
|---|---|
| 이름 | 게임 이름입니다. `game.json`의 `name`에 저장됩니다 |
| 템플릿 | 어떤 내용으로 시작할지 고릅니다. 아래 표를 참고하세요 |
| 언어 | Lua 또는 Ruby (mruby). 처음이라면 Lua를 권합니다 |

| 템플릿 | 들어 있는 것 | 이럴 때 고르세요 |
|---|---|---|
| 빈 프로젝트 | 글자 오브젝트 하나가 있는 씬 | 처음부터 직접 만들고 싶을 때 |
| 플래피버드 | 씬 하나와 컴포넌트 다섯 개로 완성된 게임 | 씬과 컴포넌트를 어떻게 나누는지 보고 싶을 때 |
| 타일맵 | 타일셋, 맵 한 장, 그 맵을 보여 주는 씬 | 맵이 있는 게임을 만들 때 |
| RPG 데모 | 「떠나기 전에」 (타이틀, 항구 마을, 여관, 이벤트, 대화, 아이템) | RPG를 만들 때 (Lua만 지원) |

프로젝트가 만들어지면 바로 열리고, 시작 씬이 탭으로 열립니다.

## 2. 실행해 보기

**F5**를 누르면 게임이 실행됩니다. 플래피버드에서는 스페이스 바를 누르거나 화면을 클릭하면 새가 날아오릅니다. 멈추려면 **Shift+F5**를 누르세요.

저장하지 않은 파일이 있으면 실행하기 전에 저장할지 물어봅니다. 게임은 디스크에 저장된 파일을 읽기 때문입니다. Enter를 누르면 모두 저장하고 실행합니다.

## 3. 값 하나 바꿔 보기

이번에는 새가 더 높이 날아오르게 바꿔 보겠습니다.

1. 왼쪽 **프로젝트** 패널에서 `scripts/lua/components/flappy/common.lua`를 엽니다.
2. `M.FLAP = -480.0` 줄을 찾아 `-600.0`으로 고칩니다. 날갯짓할 때 위로 올라가는 속도라서, 절댓값이 클수록 더 높이 납니다.
3. 게임을 켜 둔 채로 **Ctrl+S**를 눌러 저장합니다. 게임 창이 닫히지 않고 스크립트만 다시 불러와서 바뀐 값이 바로 적용됩니다. 이것을 핫 리로드라고 합니다. 이때 점수 같은 진행 상황은 처음으로 돌아갑니다.

## 프로젝트 폴더 살펴보기

플래피버드 Lua 프로젝트의 폴더는 이렇게 생겼습니다.

```
my-game/
├── game.json                  창 크기, 언어, 시작 씬
├── scripts/lua/
│   ├── main.lua               진입점. 시작 씬을 불러옵니다
│   ├── scene_loader.lua       씬 파일을 읽어 오브젝트와 컴포넌트를 만드는 모듈
│   └── components/flappy/     새, 파이프, 배경 스크롤 같은 컴포넌트
├── resources/
│   ├── scenes/flappy.json     씬 (씬 뷰에서 편집)
│   ├── audio/                 효과음
│   └── api/                   자동 완성과 언어 서버가 참고하는 엔진 API 정보
└── .luarc.json                Lua 진단 규칙
```

- `game.json`은 엔진이 가장 먼저 읽는 파일입니다. 창 크기(`windowWidth`, `windowHeight`, 기본 768x896), 언어(`script`, `lua` 또는 `mruby`), 시작 씬(`startScene`)이 들어 있습니다.
- Ruby 프로젝트라면 `scripts/lua/` 대신 `scripts/ruby/`를 씁니다.
- `.initial-editor/` 폴더에는 열어 둔 탭이나 패널 배치 같은 에디터 상태가 저장됩니다. 게임과는 상관없는 파일이라 `.gitignore`에 들어 있습니다.

## 만들어 둔 프로젝트 열기

**파일 > 프로젝트 열기**(Ctrl+O)를 선택하고 `game.json`이 있는 폴더를 고릅니다. 최근에 연 프로젝트는 시작 화면과 **파일 > 최근 프로젝트**에서 바로 열 수 있습니다.
