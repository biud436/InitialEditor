# 첫 프로젝트

프로젝트는 `game.json`이 있는 폴더입니다. 템플릿은 새 프로젝트에 복사되는 파일 묶음(씬, 스크립트, 이미지, 씬 로더)입니다. 이 문서는 플래피버드 템플릿으로 프로젝트를 만들고, 실행하고, 값을 바꿔 결과를 확인하는 절차를 설명합니다.

## 1. 프로젝트 만들기

1. 시작 화면의 **새 프로젝트** 또는 **파일 > 새 프로젝트**(Ctrl+N)를 선택합니다.
2. 프로젝트 폴더를 선택합니다.
3. 이름, 템플릿, 언어를 지정하고 **만들기**를 누릅니다.

| 항목 | 설명 |
|---|---|
| 이름 | `game.json`의 `name` 값입니다 |
| 템플릿 | 복사할 파일 묶음입니다 (아래 표) |
| 언어 | 스크립트 언어입니다. Lua 또는 Ruby(mruby). `game.json`의 `script` 값이 됩니다 |

| 템플릿 | 포함된 파일 |
|---|---|
| 빈 프로젝트 | 텍스트 오브젝트 하나가 있는 씬 |
| 플래피버드 | 씬 하나와 컴포넌트 다섯 개로 구성된 게임 |
| 타일맵 | 타일셋, 맵 한 장, 맵을 표시하는 씬, 맵 오브젝트 스키마 |
| RPG 데모 | RPG 데모 「떠나기 전에」 (타이틀, 맵 두 장, 이벤트, 아이템) |

만들기가 끝나면 프로젝트가 열리고 시작 씬이 탭으로 열립니다.

> **주의**: 파일이 있는 폴더를 선택하면 확인 창이 표시됩니다. 계속하면 같은 이름의 파일은 그대로 두고 없는 파일만 만듭니다. 기존 `game.json`이나 스크립트가 템플릿과 맞지 않으면 실행되지 않을 수 있으므로 빈 폴더를 사용합니다.

> **주의**: RPG 데모는 Lua로만 만들 수 있습니다. 이벤트를 실행하는 RPG 스크립트가 Lua로 작성되어 있습니다. Ruby 프로젝트는 mruby가 포함된 엔진에서만 실행됩니다.

## 2. 실행

**F5**를 누르면 엔진이 프로젝트를 실행합니다. 플래피버드에서는 스페이스 키 또는 마우스 왼쪽 버튼으로 새가 위로 이동합니다. **Shift+F5**로 정지합니다.

엔진은 디스크에 저장된 파일을 읽습니다. 저장하지 않은 문서가 있으면 실행 전에 저장 여부를 묻습니다. Enter를 누르면 모두 저장한 뒤 실행합니다.

## 3. 값 변경과 핫 리로드

1. **프로젝트** 패널에서 `scripts/lua/components/flappy/common.lua`를 엽니다.
2. `M.FLAP = -480.0`을 `-600.0`으로 바꿉니다. `FLAP`은 날갯짓 순간에 적용되는 세로 속도(픽셀/초)입니다. y축이 아래쪽으로 증가하므로 음수가 위쪽 방향이고, 절댓값이 클수록 높이 올라갑니다.
3. 게임이 실행 중인 상태에서 **Ctrl+S**로 저장합니다.

저장하면 핫 리로드가 실행됩니다. 엔진은 게임 창을 유지한 채 스크립트 실행 환경을 다시 만들고, 진입 스크립트를 처음부터 다시 실행합니다. 동작 방식은 [게임 실행](running.md#핫-리로드)을 참고합니다.

> **주의**: 핫 리로드는 스크립트의 모든 상태를 버립니다. 점수, 전역 변수, `scene.state`는 초기화되고 게임은 시작 씬부터 다시 시작합니다.

## 프로젝트 폴더 구조

플래피버드 Lua 프로젝트의 구조입니다.

```
my-game/
├── game.json                  프로젝트 설정
├── scripts/lua/
│   ├── main.lua               진입 스크립트. 시작 씬을 엽니다
│   ├── scene_loader.lua       씬 로더
│   ├── scene_types/           타일맵 같은 확장 오브젝트 종류
│   └── components/flappy/     컴포넌트
├── resources/
│   ├── scenes/flappy.json     씬 파일
│   ├── audio/                 효과음
│   └── api/                   엔진 API 정의 (자동 완성, 언어 서버용)
└── .luarc.json                Lua 언어 서버 진단 규칙
```

`game.json`의 항목은 다음과 같습니다.

| 키 | 의미 | 기본값 |
|---|---|---|
| `name` | 게임 이름 | 프로젝트 이름 |
| `windowWidth`, `windowHeight` | 창 크기(픽셀) | 768, 896 |
| `renderScale` | 렌더 배율. 1 이상 16 이하의 정수입니다. 논리 화면 크기는 창 크기를 이 값으로 나눈 값입니다 | 1 |
| `script` | 스크립트 언어. `lua` 또는 `mruby` | `lua` |
| `startScene` | 진입 스크립트가 처음 여는 씬의 이름 | 템플릿마다 다름 |

- Ruby 프로젝트는 `scripts/lua/` 대신 `scripts/ruby/`를 사용합니다.
- `.initial-editor/` 폴더는 에디터 상태(열린 탭, 패널 배치)를 저장합니다. 게임 실행에는 쓰이지 않으며 `.gitignore`에 포함됩니다.

> **주의**: `renderScale`은 정수로 읽습니다. 2.5를 지정하면 2로 처리됩니다.

## 프로젝트 열기

**파일 > 프로젝트 열기**(Ctrl+O)를 선택하고 `game.json`이 있는 폴더를 선택합니다. 최근 프로젝트는 시작 화면과 **파일 > 최근 프로젝트**에 표시됩니다.
