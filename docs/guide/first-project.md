# 첫 프로젝트

템플릿으로 프로젝트를 만들고 실행하기까지의 과정입니다. 여기서는 플래피버드 템플릿을 예로 듭니다.

## 1. 새 프로젝트 만들기

1. 시작 화면의 **새 프로젝트**를 누르거나 **파일 > 새 프로젝트**(Ctrl+N)를 선택합니다.
2. 프로젝트를 둘 폴더를 선택합니다. 빈 폴더가 좋습니다. 파일이 있는 폴더를 선택하면 기존 파일은 그대로 두고 없는 파일만 만든다는 확인 창이 뜹니다.
3. 새 프로젝트 창에서 이름, 템플릿, 언어를 정하고 **만들기**를 누릅니다.

| 칸 | 설명 |
|---|---|
| 이름 | 게임 이름입니다. `game.json`의 `name`에 들어갑니다. |
| 템플릿 | 시작할 내용입니다. 아래 표를 참고합니다. |
| 언어 | Lua 또는 Ruby (mruby). 처음이라면 Lua를 권합니다. |

| 템플릿 | 들어 있는 것 | 이럴 때 |
|---|---|---|
| 빈 프로젝트 | 글자 오브젝트 하나가 있는 씬 | 처음부터 직접 만들 때 |
| 플래피버드 | 씬 하나와 컴포넌트 다섯 개로 된 완성 게임 | 씬과 컴포넌트가 어떻게 나뉘는지 볼 때 |
| 타일맵 | 타일셋, 맵 한 장, 그 맵을 그리는 씬 | 맵이 있는 게임을 만들 때 |
| RPG 데모 | 「떠나기 전에」(타이틀, 항구 마을, 여관, 이벤트, 대화, 아이템) | RPG를 만들 때 (Lua 전용) |

만들기가 끝나면 프로젝트가 열리고 시작 씬이 탭에 표시됩니다.

## 2. 실행하기

**F5**를 누르면 게임이 실행됩니다. 플래피버드는 스페이스나 클릭으로 새가 날아오릅니다. **Shift+F5**로 정지합니다.

저장하지 않은 문서가 있으면 실행 전에 저장할지 묻습니다. 게임은 디스크의 파일을 읽기 때문입니다. Enter를 누르면 모두 저장하고 실행합니다.

## 3. 무언가 바꿔 보기

새가 더 높이 날아오르게 바꿔 봅니다.

1. 왼쪽 **프로젝트** 패널에서 `scripts/lua/components/flappy/common.lua`를 엽니다.
2. `M.FLAP = -480.0` 줄을 찾아 `-600.0`으로 바꿉니다. 날갯짓 순간의 위쪽 속도라서 절댓값이 클수록 높이 납니다.
3. 게임이 실행 중인 상태에서 **Ctrl+S**로 저장합니다. 게임 창을 닫지 않고 스크립트를 다시 불러와 바뀐 값이 바로 반영됩니다 (핫 리로드). 점수 같은 진행 상태는 처음으로 돌아갑니다.

## 프로젝트 폴더 구조

플래피버드 Lua 프로젝트를 예로 들면 다음과 같습니다.

```
my-game/
├── game.json                  창 크기, 언어, 시작 씬
├── scripts/lua/
│   ├── main.lua               진입점. 시작 씬을 불러옵니다
│   ├── scene_loader.lua       씬 파일을 읽어 오브젝트와 컴포넌트를 만드는 모듈
│   └── components/flappy/     새, 파이프, 배경 스크롤 같은 컴포넌트
├── resources/
│   ├── scenes/flappy.json     씬 (씬 뷰에서 편집)
│   ├── audio/                 효과음
│   └── api/                   자동 완성과 언어 서버가 읽는 엔진 API 정보
└── .luarc.json                Lua 진단 규칙
```

- `game.json`은 엔진이 가장 먼저 읽는 파일입니다. `windowWidth`, `windowHeight`(기본 768x896), `script`(`lua` 또는 `mruby`), `startScene`(시작 씬 이름)이 들어 있습니다.
- Ruby 프로젝트는 `scripts/lua/` 대신 `scripts/ruby/`를 씁니다.
- `.initial-editor/` 폴더에는 열린 탭과 패널 배치 같은 편집 상태가 저장됩니다. 게임 데이터가 아니므로 `.gitignore`에 들어 있습니다.

## 기존 프로젝트 열기

**파일 > 프로젝트 열기**(Ctrl+O)로 `game.json`이 있는 폴더를 선택합니다. 최근에 연 프로젝트는 시작 화면과 **파일 > 최근 프로젝트**에 있습니다.
