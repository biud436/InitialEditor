# 비주얼 스크립팅

코드를 직접 쓰지 않고, 노드를 선으로 연결해서 컴포넌트를 만들 수 있습니다. 그래프를 저장하면 에디터가 같은 동작을 하는 Lua와 Ruby 코드를 만들어 주기 때문에, 게임에서는 손으로 쓴 컴포넌트와 똑같이 동작합니다. 매개변수, 핫 리로드, 콘솔 오류 링크도 그대로 쓸 수 있습니다.

![그래프 편집 화면](images/graph-editor.png)

## 그래프 컴포넌트 만들기

1. **파일 > 새 그래프 컴포넌트**(Ctrl+Alt+G)를 선택하고 이름을 입력합니다. 예: `components/coin`
2. `scripts/components/coin.graph.json` 파일이 만들어지고 그래프 편집기가 열립니다.
3. 씬의 오브젝트에 `components/coin` 컴포넌트를 붙입니다 ([씬 편집](scenes.md#컴포넌트-붙이기)). 인스펙터에서 이 컴포넌트 이름을 누르면 코드가 아니라 그래프가 열립니다.

저장할 때마다 다음 파일도 함께 만들어집니다. 엔진은 그래프가 아니라 이 파일들을 읽으므로, git을 쓴다면 같이 커밋하세요.

- `scripts/lua/components/coin.lua`
- `scripts/ruby/components/coin.rb`
- 매개변수를 선언했다면 `scripts/components/coin.json`

이렇게 만들어진 코드는 첫 줄이 `-- 그래프에서 만든 파일:`로 시작하고, 스크립트 편집기에서는 읽기 전용으로 열립니다. 같은 경로에 직접 작성한 파일(첫 줄에 이 표시가 없는 파일)이 있으면, 그래프가 그 파일을 덮어쓰지 않습니다.

## 노드 다루기

| 하고 싶은 일 | 방법 |
|---|---|
| 노드 추가 | 빈 곳을 오른쪽 클릭하거나 두 번 클릭. 또는 위쪽의 **노드 추가** |
| 노드 연결 | 포트에서 다른 포트로 드래그 |
| 변수나 매개변수 노드 만들기 | 옆 창 항목 앞의 ⠿를 캔버스로 드래그. 입력 포트 위에 놓으면 노드가 생기면서 바로 연결됩니다. 상태 필드와 지역 변수는 Alt를 누른 채 놓으면 값을 바꾸는 노드가 됩니다 |
| 연결하면서 노드 추가 | 포트에서 끌어낸 선을 빈 곳에 놓기. 그 선에 연결할 수 있는 노드만 목록에 나옵니다 |
| 연결 끊기 | 선을 오른쪽 클릭하거나, Alt를 누른 채 포트를 클릭 |
| 값 입력 | 연결되지 않은 입력 포트 옆 입력란에 직접 입력 |
| 화면 이동 | 가운데나 오른쪽 버튼으로 드래그, 또는 Space를 누른 채 드래그 |
| 확대와 축소 | 마우스 휠 |
| 화면에 맞추기 | F 키, 또는 위쪽의 **전체 보기** |
| 노드 정리 | 위쪽의 **자동 정렬** |

복사, 붙여넣기, 복제, 삭제, 되돌리기는 편집 메뉴와 같은 단축키로 할 수 있습니다. 오른쪽 아래 미니맵을 클릭하면 그 위치로 바로 이동합니다.

### 메모

노드를 선택하고 위쪽의 **메모**를 누르면, 선택한 노드들을 감싸는 메모 상자가 생깁니다. 상자의 제목 줄을 드래그하면 안에 있는 노드가 함께 움직입니다. 메모는 코드에 영향을 주지 않습니다.

## 노드 종류

| 분류 | 예 |
|---|---|
| 이벤트 | init, update, render, destroy. 컴포넌트 함수와 같은 역할입니다 |
| 흐름 | 조건 분기, 값 분기, 반복 |
| 변수 | 상태 읽기와 쓰기, 변수 읽기와 쓰기, 매개변수 |
| 오브젝트 | 이 오브젝트, 오브젝트 속성 읽기와 쓰기, props 읽기와 쓰기 |
| 씬 | 오브젝트 찾기, 오브젝트 제거, 씬 전환 |
| 수학, 논리, 텍스트 | 사칙연산, 난수, 범위 제한, 비교, 그리고, 또는, 부정, 텍스트 합치기, 콘솔 출력 |
| 엔진 API | 입력, 소리, 화면 크기 등 |
| 라이브러리 | 프로젝트의 도우미 모듈 (아래 설명 참고) |

흰 마름모 모양 포트는 실행 순서를, 색이 있는 동그란 포트는 값을 나타냅니다. 이벤트 노드에서 출발해 흰 선을 따라 차례대로 실행됩니다.

## 옆 창

그래프 편집기 오른쪽 창에서는 그래프 전체에 쓰이는 값을 정합니다.

| 항목 | 설명 |
|---|---|
| 상태 필드 | 오브젝트마다 계속 유지되는 값 (속도, 남은 시간 등) |
| 지역 변수 | 한 번 실행되는 동안에만 쓰는 값 |
| 매개변수 | 씬 인스펙터에서 오브젝트마다 따로 정하는 값 |
| 노드 라이브러리 | 이 그래프에서 쓸 도우미 모듈 |
| 문제 | 비어 있는 필수 입력, 형식이 맞지 않는 연결 등 |

노드를 선택하면 그 노드의 설정도 이 창에 나옵니다.

### 매개변수를 노드 입력에 연결하기

오브젝트마다 다른 효과음을 내고 싶다면 이렇게 합니다.

1. 옆 창 **매개변수**에서 **추가**를 누르고, 이름은 `sound`, 형식은 `string`으로 정합니다.
2. 그 항목 앞의 ⠿를 효과음 재생 노드의 **파일 경로** 포트 위로 드래그합니다. 매개변수 노드가 생기면서 파일 경로에 연결됩니다.
3. 씬 인스펙터에서 오브젝트마다 `sound` 값을 입력합니다 (예: `./resources/audio/flap.wav`).

만들어지는 코드는 게임이 실행될 때 이 값을 읽습니다 (Lua는 `params.sound`, Ruby는 `@params["sound"]`). 코드는 하나지만 오브젝트마다 다른 값을 쓰게 됩니다.

## 오류가 있을 때

그래프에 문제가 있으면 코드를 만들지 않습니다. 문제가 있는 노드는 테두리 색으로 표시되고, 옆 창의 **문제** 목록에서 항목을 클릭하면 해당 노드로 이동합니다.

게임을 실행하다가 그래프로 만든 컴포넌트에서 오류가 나면, 콘솔의 오류 줄을 클릭했을 때 그래프가 열리고 그 줄을 만든 노드가 선택됩니다.

## 만들어진 코드 보기

위쪽의 **Lua 코드**, **Ruby 코드** 버튼으로 지금 그래프가 어떤 코드로 바뀌는지 볼 수 있습니다. 코드 공부에도 도움이 됩니다.

## 노드 라이브러리

게임에서 함께 쓰는 상수나 함수를 모아 둔 모듈이 있다면, 그것을 노드로 불러 쓸 수 있습니다. `*.nodes.json` 파일에 모듈의 함수와 상수를 적고, 옆 창의 **노드 라이브러리**에 추가하면 됩니다. 같은 노드라도 Lua에서는 `flappy.GRAVITY`, Ruby에서는 `FlappyCommon::GRAVITY`처럼 언어에 맞는 이름으로 바뀌어 들어갑니다.
