# 씬 편집

씬은 한 화면에 놓이는 오브젝트의 목록입니다. 타이틀 화면, 게임 화면, 게임 오버 화면처럼 화면마다 씬을 하나씩 만듭니다. 씬 파일은 `resources/scenes/<이름>.json`이고, 프로젝트 패널에서 열면 씬 뷰가 표시됩니다.

![씬 편집 화면](images/scene-editor.png)

## 오브젝트 추가

**씬 > 오브젝트 추가**에서 타입을 선택하거나, Ctrl+Shift+A로 목록에서 선택합니다.

| 타입 | 용도 | 인스펙터의 주요 속성 |
|---|---|---|
| 빈 노드 | 그림 없이 컴포넌트만 붙이는 오브젝트 (점수 관리, 적 생성 등) | 위치 |
| 스프라이트 | 그림 | 이미지, 프레임 너비와 높이, 프레임 수, 프레임 지연, 배율 |
| 텍스트 | 글자 | 글, 폰트 |
| 타일맵 | `resources/maps/`의 맵 | 맵 파일, 바닥 레이어 수 |

새 씬은 **씬 > 새 씬**(Ctrl+Shift+N)으로 만듭니다. 게임을 시작할 때 열릴 씬은 그 씬을 연 채로 **씬 > 시작 씬으로 지정**을 선택하거나 도구 모음의 씬 목록에서 바꿉니다.

## 선택과 이동

| 조작 | 결과 |
|---|---|
| 클릭 | 오브젝트 선택 |
| 빈 곳에서 끌기 | 상자 선택 |
| 선택한 오브젝트 끌기 | 이동 |
| 방향키 | 1px 이동 (Shift와 함께 10px) |
| Esc | 선택 해제 |
| 가운데 버튼, 오른쪽 버튼, Space와 끌기 | 화면 이동 |
| 휠 | 확대와 축소 (Shift나 Alt와 함께 휠은 화면 이동) |
| Ctrl+=, Ctrl+-, Ctrl+0 | 확대, 축소, 100% |

씬 뷰 위쪽 띠에서 격자, 격자 크기, 스냅, 줌, **카메라에 맞추기**를 바꿉니다. 씬 뷰의 카메라 사각형은 게임 화면의 범위이고, 크기는 `game.json`의 창 크기입니다.

편집 메뉴의 복사(Ctrl+C), 붙여넣기(Ctrl+V), 복제(Ctrl+D), 삭제(Delete)가 선택한 오브젝트에 적용됩니다. 모든 편집은 Ctrl+Z로 되돌릴 수 있습니다.

> 씬 뷰는 편집용 미리보기입니다. 컴포넌트가 움직이거나 그리는 것은 표시되지 않으므로, 실제 화면은 **실행 > 현재 씬부터 실행**(Ctrl+F5)으로 확인합니다.

## 계층 패널

계층 패널의 목록은 그리는 순서입니다. 위에 있는 오브젝트가 먼저 그려지므로, 아래에 있는 오브젝트가 화면에서는 앞에 보입니다.

- 행을 끌어 순서를 바꿉니다.
- 눈 아이콘으로 표시를 켜고 끕니다. 인스펙터의 **표시**와 같은 값이라, 끈 오브젝트는 게임에서도 처음에 보이지 않습니다.
- F2, Enter, 두 번 클릭으로 id(이름)를 바꿉니다. 스크립트가 이 id로 오브젝트를 찾으므로 겹치지 않게 짓습니다.

## 인스펙터

선택한 오브젝트의 속성을 편집합니다.

- **공통**: id, x, y, 표시
- **타입별 속성**: 위 표 참고. 스프라이트의 이미지는 프로젝트의 PNG에서 선택합니다.
- **스크립트**: 오브젝트에 붙은 컴포넌트 목록
- **검사**: 엔진이 이 씬을 읽을 때 문제가 될 것 (겹치는 id, 비어 있는 이미지 칸, 선언과 맞지 않는 매개변수, 열 수 없는 맵 파일 등)

## 컴포넌트 붙이기

컴포넌트는 오브젝트의 동작을 정하는 스크립트입니다. 새의 날갯짓, 파이프 생성, 점수 계산이 각각 컴포넌트입니다.

1. 오브젝트를 선택하고 인스펙터의 **스크립트 추가**를 누릅니다.
2. 논리 이름을 적습니다. 예: `components/player`. Lua 프로젝트면 `scripts/lua/components/player.lua`를 가리킵니다.
3. **파일이 없으면 생성**을 켜 두면 기본 함수가 들어 있는 파일이 만들어집니다.

컴포넌트가 여럿이면 목록의 순서대로 실행됩니다. 위아래 화살표 버튼으로 순서를 바꾸고, 이름을 누르면 스크립트(그래프로 만든 컴포넌트는 그래프)가 열립니다. 컴포넌트 작성법은 [스크립트 편집](scripts.md)에 있습니다.

## 매개변수

같은 컴포넌트를 여러 오브젝트에 붙이면서 값만 다르게 주고 싶을 때 씁니다. 예를 들어 `mover` 컴포넌트에 속도를 매개변수로 두면, 오브젝트마다 인스펙터에서 속도를 다르게 정할 수 있습니다.

매개변수는 `scripts/components/<논리 이름>.json`에 선언합니다. Lua와 Ruby가 같은 파일을 씁니다.

```json
{
  "version": 1,
  "fields": [
    { "key": "speed", "type": "number", "label": "속도", "default": 60, "min": 0 },
    { "key": "target", "type": "object", "label": "대상" }
  ]
}
```

| type | 인스펙터 입력 |
|---|---|
| string, text | 한 줄 글, 여러 줄 글 |
| number, integer | 숫자 (min, max로 범위 지정) |
| boolean | 체크 상자 |
| enum | `values` 중 하나를 선택 |
| object | 같은 씬의 다른 오브젝트 id |

선언이 있으면 인스펙터가 그 필드로 입력 칸을 만듭니다. 기본값과 다른 값만 씬 파일에 저장되고, **기본값 복원**으로 되돌립니다. 선언 파일이 아직 없으면 인스펙터의 **매개변수 선언 만들기**가 지금 값의 형식으로 파일을 만들어 줍니다.

스크립트에서는 이렇게 받습니다.

```lua
-- Lua: 훅의 마지막 인자
function Mover.update(obj, scene, elapsed, params)
  obj.x = obj.x + params.speed * elapsed / 1000
end
```

```ruby
# Ruby: initialize 의 인자
class Mover
  def initialize(params = {})
    @speed = params["speed"]
  end
end
```

## 타일맵 오브젝트

**씬 > 오브젝트 추가 > 타일맵**으로 추가하고 인스펙터에서 맵 파일을 선택하면, 씬 뷰가 그 맵을 실제 타일로 그립니다.

- **바닥 레이어 수**만큼의 앞 레이어는 모든 오브젝트 아래에, 나머지 레이어는 모든 오브젝트 위에 그려집니다. 캐릭터가 나무 뒤로 지나가게 할 때 씁니다.
- 타일맵은 배경처럼 다룹니다. 한 번 눌러 선택한 뒤에 끌어야 옮겨지고, 선택하지 않은 맵 위에서 끌면 상자 선택이 됩니다.
- 인스펙터의 **맵 열기**로 그 맵을 맵 뷰에서 편집합니다 ([맵 편집](maps.md)).
