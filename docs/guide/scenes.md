# 씬 편집

씬은 한 화면을 이루는 오브젝트의 모음입니다. 타이틀 화면, 게임 화면, 게임 오버 화면처럼 화면마다 씬을 하나씩 만듭니다. 씬 파일은 `resources/scenes/<이름>.json`에 있고, 프로젝트 패널에서 열면 씬 뷰가 나타납니다.

![씬 편집 화면](images/scene-editor.png)

## 오브젝트 추가하기

**씬 > 오브젝트 추가**에서 종류를 고르거나, Ctrl+Shift+A를 눌러 목록에서 고릅니다.

| 종류 | 용도 | 인스펙터에서 정하는 것 |
|---|---|---|
| 빈 노드 | 그림 없이 컴포넌트만 붙이는 오브젝트 (점수 관리, 적 생성 등) | 위치 |
| 스프라이트 | 이미지 | 이미지, 프레임 너비와 높이, 프레임 수, 프레임 지연, 배율 |
| 텍스트 | 글자 | 내용, 폰트 |
| 타일맵 | `resources/maps/`에 있는 맵 | 맵 파일, 바닥 레이어 수 |

새 씬은 **씬 > 새 씬**(Ctrl+Shift+N)으로 만듭니다. 게임을 시작할 때 처음 열릴 씬을 바꾸려면, 그 씬을 열어 둔 채 **씬 > 시작 씬으로 지정**을 선택하거나 도구 모음의 씬 목록에서 고르면 됩니다.

## 선택과 이동

| 조작 | 결과 |
|---|---|
| 클릭 | 오브젝트 선택 |
| 빈 곳에서 드래그 | 여러 개를 한꺼번에 선택 |
| 선택한 오브젝트를 드래그 | 이동 |
| 방향키 | 1px씩 이동 (Shift를 누르면 10px) |
| Esc | 선택 해제 |
| 가운데 버튼이나 오른쪽 버튼으로 드래그, Space를 누른 채 드래그 | 화면 이동 |
| 마우스 휠 | 확대와 축소 (Shift나 Alt를 누르면 화면 이동) |
| Ctrl+=, Ctrl+-, Ctrl+0 | 확대, 축소, 100% |

씬 뷰 위쪽에서 격자, 격자 크기, 스냅, 줌을 바꾸고 **카메라에 맞추기**로 게임 화면 영역을 한눈에 볼 수 있습니다. 씬 뷰에 보이는 카메라 사각형이 실제 게임 화면의 범위이고, 크기는 `game.json`의 창 크기를 따릅니다.

복사(Ctrl+C), 붙여넣기(Ctrl+V), 복제(Ctrl+D), 삭제(Delete)는 선택한 오브젝트에 적용됩니다. 실수했다면 Ctrl+Z로 언제든 되돌릴 수 있습니다.

> 씬 뷰는 편집을 위한 미리보기라서, 컴포넌트가 오브젝트를 움직이거나 그리는 모습은 보이지 않습니다. 실제 화면은 **실행 > 현재 씬부터 실행**(Ctrl+F5)으로 확인하세요.

## 계층 패널

계층 패널의 목록 순서가 곧 그리는 순서입니다. 위에 있는 오브젝트부터 그려지기 때문에, 아래쪽에 있는 오브젝트일수록 화면에서는 앞에 보입니다.

- 항목을 드래그해서 순서를 바꿉니다.
- 눈 아이콘으로 오브젝트를 보이거나 숨깁니다. 인스펙터의 **표시**와 같은 값이라서, 숨긴 오브젝트는 게임을 시작할 때도 보이지 않습니다.
- F2나 Enter를 누르거나 두 번 클릭하면 id(이름)를 바꿀 수 있습니다. 스크립트는 이 id로 오브젝트를 찾으므로 다른 오브젝트와 겹치지 않게 지어 주세요.

## 인스펙터

선택한 오브젝트의 속성을 편집합니다.

- **공통 속성**: id, x, y, 표시
- **종류별 속성**: 위 표를 참고하세요. 스프라이트의 이미지는 프로젝트에 있는 PNG 중에서 고릅니다.
- **스크립트**: 오브젝트에 붙은 컴포넌트 목록
- **검사**: 엔진이 씬을 읽을 때 문제가 될 만한 것들 (겹치는 id, 비어 있는 이미지, 선언과 맞지 않는 매개변수, 열 수 없는 맵 파일 등)

## 컴포넌트 붙이기

컴포넌트는 오브젝트가 어떻게 움직일지 정하는 스크립트입니다. 플래피버드라면 새의 날갯짓, 파이프 생성, 점수 계산이 각각 하나의 컴포넌트입니다.

1. 오브젝트를 선택하고 인스펙터에서 **스크립트 추가**를 누릅니다.
2. 논리 이름을 입력합니다. 예를 들어 `components/player`라고 쓰면, Lua 프로젝트에서는 `scripts/lua/components/player.lua`를 뜻합니다.
3. **파일이 없으면 생성**을 켜 두면 기본 함수가 들어 있는 파일을 만들어 줍니다.

컴포넌트가 여러 개면 목록 순서대로 실행됩니다. 위아래 화살표로 순서를 바꿀 수 있고, 이름을 누르면 스크립트가 열립니다. 그래프로 만든 컴포넌트라면 그래프가 열립니다. 컴포넌트를 작성하는 방법은 [스크립트 편집](scripts.md)에서 다룹니다.

## 매개변수

같은 컴포넌트를 여러 오브젝트에 붙이되 값만 다르게 주고 싶을 때 씁니다. 예를 들어 `mover` 컴포넌트의 속도를 매개변수로 만들어 두면, 오브젝트마다 인스펙터에서 속도를 따로 정할 수 있습니다.

매개변수는 `scripts/components/<논리 이름>.json` 파일에 선언합니다. Lua와 Ruby가 같은 파일을 함께 씁니다.

```json
{
  "version": 1,
  "fields": [
    { "key": "speed", "type": "number", "label": "속도", "default": 60, "min": 0 },
    { "key": "target", "type": "object", "label": "대상" }
  ]
}
```

| type | 인스펙터에서 입력하는 방법 |
|---|---|
| string, text | 한 줄 텍스트, 여러 줄 텍스트 |
| number, integer | 숫자 (min, max로 범위 제한) |
| boolean | 체크 상자 |
| enum | `values` 중 하나를 고름 |
| object | 같은 씬에 있는 다른 오브젝트의 id |

선언 파일이 있으면 인스펙터에 그 항목들의 입력란이 생깁니다. 씬 파일에는 기본값과 다른 값만 저장되고, **기본값 복원**을 누르면 원래대로 돌아갑니다. 아직 선언 파일이 없다면 인스펙터의 **매개변수 선언 만들기**를 누르세요. 지금 들어 있는 값을 보고 선언 파일을 만들어 줍니다.

스크립트에서는 이렇게 받아서 씁니다.

```lua
-- Lua: 함수의 마지막 인자로 받습니다
function Mover.update(obj, scene, elapsed, params)
  obj.x = obj.x + params.speed * elapsed / 1000
end
```

```ruby
# Ruby: initialize 의 인자로 받습니다
class Mover
  def initialize(params = {})
    @speed = params["speed"]
  end
end
```

## 타일맵 오브젝트

**씬 > 오브젝트 추가 > 타일맵**으로 추가한 뒤 인스펙터에서 맵 파일을 고르면, 씬 뷰에 그 맵이 실제 타일로 그려집니다.

- 앞쪽 레이어 중 **바닥 레이어 수**만큼은 모든 오브젝트 아래에, 나머지 레이어는 모든 오브젝트 위에 그려집니다. 캐릭터가 나무 뒤로 지나가는 장면 같은 것을 만들 때 씁니다.
- 타일맵은 배경처럼 다뤄집니다. 한 번 클릭해서 선택한 다음에 드래그해야 움직이고, 선택하지 않은 맵 위에서 드래그하면 여러 개 선택이 됩니다.
- 맵을 고치려면 인스펙터의 **맵 열기**를 누르세요. 맵 뷰에서 편집할 수 있습니다 ([맵 편집](maps.md)).
