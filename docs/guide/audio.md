# 소리

엔진은 SDL_mixer 라이브러리로 소리를 재생합니다. 소리는 두 종류입니다.

- **효과음**: 짧은 소리입니다. 여러 개를 동시에 재생할 수 있습니다.
- **배경 음악**: 한 번에 하나만 재생되는 긴 소리입니다.

## 지원 형식

| 형식 | 지원 |
|---|---|
| WAV | 지원 |
| OGG (Vorbis) | 지원 |
| MP3, FLAC, MIDI 등 | 배포용 엔진, Android, 웹판에서는 지원하지 않습니다 |

효과음은 WAV, 배경 음악은 OGG를 권장합니다.

## 재생 함수

| 함수 (Lua) | 함수 (Ruby) | 동작 |
|---|---|---|
| `Audio.PlaySound(path, id, loop)` | `Audio.play_sound(path, id, loop = false)` | 효과음을 읽어 재생합니다 |
| `Audio.PlayMusic(path, id, loop)` | `Audio.play_music(path, id, loop = true)` | 배경 음악을 읽어 재생합니다 |
| `Audio.StopMusic()`, `PauseMusic()`, `ResumeMusic()` | `stop_music`, `pause_music`, `resume_music` | 배경 음악 정지, 일시 정지, 재개 |
| `Audio.FadeOutMusic(ms)` | `fade_out_music(ms)` | 배경 음악을 지정한 시간 동안 줄이며 정지 |
| `Audio.SetVolume(v)` | `Audio.volume = v` | 음량(0~255) |

인자의 의미는 다음과 같습니다.

- `path`: 소리 파일의 경로입니다. 프로젝트 폴더 기준이며, 파일 이름까지 포함해야 합니다 (예: `./resources/audio/flap.wav`).
- `id`: 읽은 소리를 메모리에 저장할 때 쓰는 이름입니다. 같은 `id`로 다시 재생하면 파일을 다시 읽지 않고 저장된 소리를 재생합니다.
- `loop`: 반복 방식입니다. 아래 표를 참고합니다.

| `loop` 값 | 효과음 | 배경 음악 |
|---|---|---|
| `false` | 한 번 재생 | 한 번 재생 |
| `true` 또는 -1 | 무한 반복 | 무한 반복 |
| 숫자 N | 추가 반복 횟수. 0이면 한 번, 1이면 두 번 재생 | 재생 횟수 |

> **주의**: Lua에서는 세 인자를 모두 지정해야 합니다. `Audio.PlaySound(path, id)`처럼 `loop`를 생략하면 아무 동작도 하지 않습니다.

## 동작 방식

### 효과음 재생 과정

1. `id`로 저장된 소리가 있는지 확인합니다. 있으면 그 소리를 사용하고, `path`는 무시합니다.
2. 없으면 `path`의 파일을 읽어 `id`로 저장합니다. 읽기에 실패하면 아무것도 저장하지 않고 종료합니다.
3. 비어 있는 재생 채널을 찾아 재생합니다. 채널은 8개입니다.

> **주의: 같은 id, 다른 파일**
>
> 소리는 `id`로만 구분됩니다. `Audio.PlaySound("./resources/audio/hit.wav", "se", 0)` 다음에 `Audio.PlaySound("./resources/audio/coin.wav", "se", 0)`을 호출하면 두 번째 호출도 `hit.wav`를 재생합니다. 서로 다른 파일에는 서로 다른 `id`를 사용합니다. 파일 경로를 그대로 `id`로 쓰면 이 문제가 생기지 않습니다. 비주얼 스크립팅의 효과음 노드는 이름을 비워 두면 파일 경로를 `id`로 사용합니다.

> **주의: 읽기 실패**
>
> 파일이 없거나 경로가 폴더(`./resources/audio/`)이면 소리가 재생되지 않고 오류 메시지도 출력되지 않습니다. Lua 함수는 아무 값도 반환하지 않고, Ruby 함수는 `false`를 반환합니다. 소리가 나지 않으면 경로에 파일 이름과 확장자가 포함되어 있는지 확인합니다.

> **주의: 동시 재생 수**
>
> 효과음 채널은 8개입니다. 8개가 모두 재생 중이면 새 효과음은 재생되지 않습니다. 매 틱 효과음을 재생하면(예: 키를 누르고 있는 동안 `IsKeyPress`로 재생) 채널이 곧 가득 찹니다. 효과음은 `IsKeyDown`처럼 한 번만 참이 되는 조건에서 재생합니다.

> **주의: 무한 반복 효과음**
>
> 효과음을 정지하는 함수는 없습니다. `loop`를 `true`나 -1로 재생한 효과음은 게임이 끝날 때까지 재생됩니다. 계속 재생할 소리는 배경 음악으로 재생합니다.

> **주의: 메모리**
>
> 한 번 읽은 효과음은 게임이 끝날 때까지 메모리에 남습니다. 서로 다른 `id`로 많은 파일을 읽으면 메모리 사용량이 계속 늘어납니다.

### 배경 음악 전환

- 배경 음악은 재생을 시작할 때 1초 동안 음량을 키우며 시작합니다.
- 다른 `id`의 배경 음악을 재생하면, 현재 곡을 1초 동안 줄이며 정지한 뒤 새 곡을 1초 동안 키우며 시작합니다. 두 곡이 겹쳐 재생되지는 않습니다.
- 재생 중인 곡과 같은 `id`로 다시 재생하면 곡이 처음부터 다시 시작됩니다.
- 이전 곡은 전환이 끝날 때 메모리에서 해제됩니다.

> **주의**: 배경 음악도 `id`로만 구분됩니다. 같은 `id`로 다른 파일을 재생하면 처음 읽은 곡이 다시 재생됩니다. 곡마다 다른 `id`를 사용하거나, 곡을 바꾸기 전에 `Audio.StopMusic()`과 `Audio.ReleaseMusic(id)`로 이전 곡을 해제합니다.

### 음량

`Audio.SetVolume(v)`는 0~255 범위의 값을 받아 배경 음악과 모든 효과음 채널에 함께 적용합니다. 효과음만 따로 조절하는 함수는 없습니다.
