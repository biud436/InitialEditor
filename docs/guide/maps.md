# 맵

맵은 타일 배치, 통행 정보, 맵 오브젝트를 담은 JSON 파일입니다. 경로는 `resources/maps/<이름>.json`입니다. 맵 파일을 열면 맵 뷰가 열리고 팔레트, 레이어, 맵 오브젝트 패널이 함께 열립니다. **창 > 레이아웃 > 타일맵**은 맵 편집용 패널 배치를 적용합니다.

![맵 편집 화면](images/map-editor.png)

## 맵 파일 구조

| 키 | 의미 |
|---|---|
| `version` | 형식 버전. 1 또는 2. 에디터는 2로 저장합니다 |
| `width`, `height` | 맵 크기(타일 수) |
| `tileWidth`, `tileHeight` | 타일 한 칸의 크기(픽셀) |
| `tilesets` | 타일셋 목록. 각 항목은 `image`(PNG 경로), `firstGid`(첫 타일 번호, 1 이상), `columns`(이미지의 가로 타일 수) |
| `layers` | 레이어 목록. 각 항목은 `name`과 `data`(`width × height`개의 타일 번호) |
| `collision` | 통행 정보 (`width × height`개의 값). 생략할 수 있습니다 |
| `objects` | 맵 오브젝트 목록 (픽셀 좌표) |
| `events` | RPG 이벤트 목록 (타일 좌표) |

엔진은 `objects`와 `events`를 읽지 않습니다. 이 두 항목은 게임 스크립트(RPG 스크립트 등)가 읽습니다. 에디터는 알지 못하는 키도 저장할 때 그대로 유지합니다.

### 타일 번호

레이어의 `data`는 타일 번호의 배열입니다. 칸 (x, y)의 번호는 `data[y × width + x]`에 있습니다(x, y는 0부터).

- 0 이하의 번호는 빈 칸입니다.
- 번호는 `firstGid`가 그 번호 이하인 타일셋 중 `firstGid`가 가장 큰 타일셋에서 찾습니다.
- 타일셋 안의 위치는 `n = 번호 - firstGid`일 때, 가로 `(n % columns) × tileWidth`, 세로 `floor(n / columns) × tileHeight`입니다. 타일 사이 간격과 여백은 없습니다.

> **주의**: 타일 번호는 타일셋 이미지 안의 위치로 계산됩니다. 사용 중인 타일셋 이미지에서 타일의 위치를 옮기거나 가로 타일 수를 바꾸면, 이미 배치한 번호가 다른 타일을 가리키게 됩니다. 새 타일은 이미지 아래쪽에 줄을 추가해 넣습니다. 아래쪽에 추가한 줄은 기존 번호에 영향을 주지 않습니다.

> **주의**: 타일셋의 `image` 경로는 맵 파일 위치가 아니라 프로젝트 폴더 기준입니다. 타일셋 이미지를 읽지 못하면 맵 전체를 읽지 못합니다.

## 맵 만들기

**맵 > 새 맵**(Ctrl+Alt+M)에서 다음 항목을 지정합니다.

| 항목 | 설명 |
|---|---|
| 이름 | 파일 이름. `resources/maps/<이름>.json`으로 저장됩니다 |
| 크기 (타일) | 가로, 세로 타일 수 |
| 타일 크기 (px) | 타일 한 칸의 크기 (보통 16 또는 32) |
| 타일셋 | 프로젝트의 PNG 파일 |
| 레이어 | 쉼표로 구분한 레이어 이름. 앞에 적은 레이어부터 아래에 그려집니다 |

## 타일 배치

1. **팔레트**에서 타일을 클릭합니다. 드래그하면 사각형 범위의 여러 타일을 선택합니다. 1x, 2x, 3x는 팔레트 표시 배율입니다.
2. **레이어** 패널에서 대상 레이어를 선택합니다. 대상 레이어는 맵 뷰 위쪽의 "대상"에 표시됩니다.
3. 도구를 선택하고 맵에 배치합니다.

| 도구 | 키 | 동작 |
|---|---|---|
| 펜 | B | 클릭하거나 드래그한 칸에 선택한 타일 배치 |
| 사각형 | R | 드래그한 사각형 영역을 선택한 타일로 채우기 |
| 채우기 | G | 클릭한 칸과 같은 타일이 연결된 영역을 채우기 |
| 지우개 | E | 타일을 빈 칸(0)으로 바꾸기 |
| 스포이드 | I | 클릭한 칸의 타일을 팔레트 선택으로 가져오기 |
| 통행 | C | 통행 정보 편집 (아래 설명) |
| 오브젝트 | V | 맵 오브젝트 선택과 이동 |

마우스 버튼을 누르고 놓을 때까지의 편집이 되돌리기(Ctrl+Z) 한 단계입니다.

### 맵 뷰 조작

| 조작 | 동작 |
|---|---|
| 마우스 휠 | 커서 위치 기준 확대, 축소 |
| Shift+휠, 가운데 버튼 드래그, Space+드래그 | 화면 이동 |
| Ctrl+=, Ctrl+-, Ctrl+0 | 확대, 축소, 100% |
| 맵 전체 보기 | 맵 전체가 보이도록 배율 조정 |

맵 뷰 위쪽의 **격자**, **통행**, **오브젝트** 버튼은 각각의 표시를 켜고 끕니다. **맵 > 위 레이어 흐리게**는 대상 레이어보다 위에 있는 레이어를 흐리게 표시합니다.

## 레이어

레이어는 순서대로 겹쳐 그리는 타일 배열입니다. 레이어 패널에서는 위쪽 항목이 나중에(위에) 그려집니다.

- **보임** 버튼은 맵 뷰에서의 표시만 바꿉니다. 숨긴 레이어에는 배치할 수 없습니다.
- 이름을 두 번 클릭하면 바꿀 수 있습니다.
- **추가**, **삭제**, **위로**, **아래로** 버튼으로 레이어를 관리합니다. 삭제도 되돌릴 수 있습니다.

엔진은 레이어를 아래부터 순서대로, 각 레이어는 위쪽 줄부터 왼쪽에서 오른쪽으로 그립니다. 화면 밖의 타일은 그리지 않습니다. 타일 애니메이션, 시차 스크롤, 레이어별 불투명도는 지원하지 않습니다.

> **주의**: 레이어 번호는 Lua 함수에서 1부터, Ruby 메서드에서 0부터 셉니다. 스크립트에서 레이어를 지정할 때 언어에 맞는 번호를 사용합니다.

## 통행

통행 정보는 맵 전체에 하나만 있는 배열입니다(레이어별이 아닙니다). 값이 0이면 지나갈 수 있는 칸, 0이 아니면 지나갈 수 없는 칸입니다. `collision`이 없으면 모든 칸을 지나갈 수 있습니다.

- 통행 도구(C)에서 왼쪽 버튼은 지나갈 수 없는 칸(1), 오른쪽 버튼 또는 Alt+왼쪽 버튼은 지나갈 수 있는 칸(0)으로 바꿉니다.
- **통행** 버튼 또는 **맵 > 통행 오버레이**로 지나갈 수 없는 칸을 표시합니다.
- 스크립트에서는 `Tilemap.IsPassable(map, x, y)`(Ruby는 `map.passable?(x, y)`)로 판정합니다.

> **주의**: `IsPassable`의 x, y는 픽셀이 아니라 타일 좌표(0부터)입니다. 맵 밖의 좌표는 지나갈 수 없는 칸으로 판정됩니다.

## 맵 오브젝트

맵 오브젝트는 맵 파일의 `objects`에 저장되는 항목(몬스터, 시작 지점, 표지 등)입니다. 종류와 종류별 속성은 프로젝트의 스키마 파일 `resources/schema/map-objects.json`이 정의합니다. 에디터는 스키마에 따라 추가 버튼과 인스펙터 입력란을 만듭니다. 타일맵 템플릿의 스키마에는 `marker` 종류 하나가 정의되어 있습니다.

```json
{
  "version": 1,
  "types": [
    { "type": "marker", "label": "표식", "shape": "point", "color": "accent",
      "fields": [{ "name": "label", "type": "string", "label": "이름" }] }
  ]
}
```

- **맵 오브젝트** 패널의 종류별 추가 버튼으로 만듭니다.
- 오브젝트 도구(V)로 선택하고 드래그해 이동합니다. 순찰 범위가 있는 오브젝트는 범위의 양 끝도 드래그할 수 있습니다.
- 속성은 인스펙터에서 편집합니다. 필수 항목이 비어 있으면 검사 결과에 표시됩니다.
- 복사, 붙여넣기, 복제(Ctrl+D), 삭제를 사용할 수 있습니다. 붙여넣은 오브젝트는 한 칸 오른쪽에 배치됩니다.

> **주의**: 맵 오브젝트의 좌표는 픽셀 단위이고, 이벤트와 통행 정보는 타일 단위입니다. 스크립트에서 둘을 비교할 때는 타일 크기로 변환합니다.

## 크기 변경

**맵 > 크기 바꾸기** 또는 맵 뷰 위쪽의 크기 표시를 클릭합니다. 새 크기와 기준점(아홉 위치 중 하나)을 지정하면 기준점 쪽의 내용을 유지하고 반대쪽을 늘리거나 잘라냅니다.

> **주의**: 줄인 영역의 타일과 통행 정보는 삭제됩니다. 맵 밖으로 나가는 맵 오브젝트는 삭제하지 않고 목록으로 알려 줍니다. 이 오브젝트는 직접 옮기거나 삭제합니다.

## 이 맵에서 실행

맵 탭에서 **맵 > 이 맵에서 실행**(Ctrl+F5)을 선택하면 이 맵에서 게임을 시작합니다.

- 맵 오브젝트를 하나 선택했으면 그 위치, 아니면 커서 위치나 화면 가운데에서 시작합니다.
- 엔진에 전달할 환경 변수는 스키마 파일의 `play` 항목이 정의합니다. `play`의 `maps`에 맵 이름 패턴 목록이 있으면 일치하는 맵에서만 실행합니다. 실행할 수 없는 맵이면 실행하지 않고 이유를 콘솔과 알림에 표시합니다.

## 씬에서 맵 사용

게임에서 맵을 표시하려면 씬에 타일맵 오브젝트를 추가하고 맵 파일을 지정합니다 ([씬](scenes.md#타일맵-오브젝트)). 타일맵 템플릿으로 만든 프로젝트에는 이 설정이 되어 있습니다.

## 저장 형식

저장(Ctrl+S)하면 엔진이 읽는 형식으로 저장합니다. 들여쓰기는 2칸이고, 레이어의 타일 배열은 맵의 한 줄이 파일의 한 줄입니다. 버전 관리 도구에서 바뀐 칸을 줄 단위로 확인할 수 있습니다.
