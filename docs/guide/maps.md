# 맵 편집

`resources/maps/`의 맵 파일(`.json`)을 열면 맵 뷰가 표시됩니다. 타일을 칠하고, 통행을 정하고, 몬스터나 시작 지점 같은 오브젝트를 배치합니다. 맵을 열 때 팔레트, 레이어, 맵 오브젝트 패널이 자동으로 붙습니다. 전체 배치는 **창 > 레이아웃 > 타일맵**이 편합니다.

![맵 편집 화면](images/map-editor.png)

## 새 맵

**맵 > 새 맵**(Ctrl+Alt+M)에서 정합니다.

| 칸 | 설명 |
|---|---|
| 이름 | 파일 이름. `resources/maps/<이름>.json`으로 저장됩니다 |
| 크기 (타일) | 가로와 세로 타일 수 |
| 타일 크기 (px) | 타일 한 칸의 픽셀 크기 (보통 16 또는 32) |
| 타일셋 | 프로젝트의 PNG 가운데 하나 |
| 레이어 | 쉼표로 구분한 레이어 이름. 앞에 적은 레이어가 아래에 그려집니다 |

## 타일 칠하기

1. **팔레트**에서 타일을 누릅니다. 끌면 여러 칸을 한꺼번에 선택합니다. 팔레트 위의 1x, 2x, 3x로 팔레트 확대를 바꿉니다.
2. **레이어** 패널에서 칠할 레이어를 선택합니다. 맵 뷰 위쪽의 "대상"에 지금 레이어가 표시됩니다.
3. 도구를 선택하고 맵에 칠합니다.

| 도구 | 키 | 동작 |
|---|---|---|
| 펜 | B | 누르거나 끌어서 칠하기 |
| 사각형 | R | 끌어서 사각형 영역 채우기 |
| 채우기 | G | 같은 타일이 이어진 영역 채우기 |
| 지우개 | E | 타일 지우기 |
| 스포이드 | I | 맵의 타일을 팔레트 선택으로 가져오기 |
| 통행 | C | 지나갈 수 없는 칸 정하기 (아래 참고) |
| 오브젝트 | V | 맵 오브젝트 선택과 이동 |

붓질 한 번이 되돌리기(Ctrl+Z) 한 단계입니다.

## 화면 이동과 확대

| 조작 | 결과 |
|---|---|
| 휠 | 커서 위치 기준 확대와 축소 |
| Shift+휠, 가운데 버튼 끌기, Space+끌기 | 화면 이동 |
| Ctrl+=, Ctrl+-, Ctrl+0 | 확대, 축소, 100% |
| 맵 전체 보기 (위쪽 버튼) | 맵 전체가 들어오게 맞춤 |

위쪽 띠의 **격자**, **통행**, **오브젝트** 버튼으로 각 오버레이를 켜고 끕니다. **맵 > 위 레이어 흐리게**를 켜면 지금 칠하는 레이어보다 위에 있는 레이어가 흐려져 아래 레이어를 칠하기 쉽습니다.

## 레이어

레이어 패널의 목록은 위에 있는 레이어가 나중에(위에) 그려집니다.

- **보임** 버튼으로 맵 뷰에서 레이어를 숨깁니다. 숨긴 레이어는 칠할 수 없습니다.
- 이름을 두 번 눌러 바꿉니다.
- 아래쪽 **추가**, **삭제**, **위로**, **아래로**로 레이어를 관리합니다. 삭제도 되돌릴 수 있습니다.

## 통행

통행 도구(C)를 선택하고 왼쪽 버튼으로 칠하면 지나갈 수 없는 칸, 오른쪽 버튼(또는 Alt와 함께)으로 칠하면 지나갈 수 있는 칸이 됩니다. 위쪽의 **통행** 버튼이나 **맵 > 통행 오버레이**로 막힌 칸을 겹쳐 봅니다. 스크립트에서는 엔진의 `IsPassable`(Ruby는 `passable?`)로 읽습니다.

## 맵 오브젝트

몬스터, 시작 지점, 표지처럼 맵 위에 놓이는 것들입니다. 어떤 타입이 있고 각 타입에 어떤 속성이 있는지는 프로젝트의 `resources/schema/map-objects.json`이 정합니다. 타일맵 템플릿에는 예시로 `marker` 타입 하나가 들어 있고, 필요한 타입을 이 파일에 더해 씁니다.

```json
{
  "version": 1,
  "types": [
    { "type": "marker", "label": "표식", "shape": "point", "color": "accent",
      "fields": [{ "name": "label", "type": "string", "label": "이름" }] }
  ]
}
```

- **맵 오브젝트** 패널의 타입별 추가 버튼으로 만듭니다.
- 오브젝트 도구(V)로 선택하고 끌어 옮깁니다. 순찰 범위가 있는 오브젝트는 범위의 손잡이도 끌 수 있습니다.
- 인스펙터에서 스키마에 적힌 속성을 편집합니다. 필수 칸이 비면 검사 결과에 표시됩니다.
- 복사, 붙여넣기, 복제(Ctrl+D), 삭제가 됩니다. 붙인 오브젝트는 한 칸 오른쪽에 놓입니다.

## 크기 바꾸기

**맵 > 크기 바꾸기** 또는 맵 뷰 위쪽의 크기 표시를 누릅니다. 새 크기와 기준점(아홉 칸 중 하나)을 정하면, 기준점 쪽의 내용은 그대로 있고 반대쪽이 늘어나거나 잘립니다. 맵 밖으로 나가게 되는 오브젝트는 지우지 않고 알려 줍니다.

## 이 맵에서 바로 실행

맵 탭에서 **맵 > 이 맵에서 실행**(Ctrl+F5)을 선택하면 이 맵에서 게임을 시작합니다.

- 오브젝트를 하나 선택했으면 그 자리에서, 아니면 커서 위치나 화면 가운데에서 시작합니다.
- 어떤 환경 변수로 엔진을 띄울지는 스키마의 `play` 항목이 정합니다. 이 기능을 지원하지 않는 맵이면 실행하지 않고 이유를 알려 줍니다.

## 씬에서 맵 쓰기

맵을 게임 화면에 표시하려면 씬에 타일맵 오브젝트를 추가하고 이 맵 파일을 선택합니다 ([씬 편집](scenes.md#타일맵-오브젝트)). 타일맵 템플릿으로 만든 프로젝트는 이미 연결되어 있어, 맵을 칠하고 저장한 뒤 F5로 바로 확인할 수 있습니다.

## 저장 형식

저장(Ctrl+S)하면 엔진이 읽는 형식 그대로 씁니다. 타일 배열은 맵의 한 줄이 파일의 한 줄이라 git에서 바뀐 칸을 알아보기 쉽고, 에디터가 모르는 키도 그대로 남습니다.
