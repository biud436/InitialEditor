# 맵 편집

`resources/maps/`에 있는 맵 파일(`.json`)을 열면 맵 뷰가 나타납니다. 여기서 타일을 칠하고, 지나갈 수 없는 곳을 정하고, 몬스터나 시작 지점 같은 오브젝트를 배치합니다. 맵을 열면 팔레트, 레이어, 맵 오브젝트 패널이 함께 열리는데, **창 > 레이아웃 > 타일맵**을 고르면 맵 작업에 맞게 한 번에 정리됩니다.

![맵 편집 화면](images/map-editor.png)

## 새 맵 만들기

**맵 > 새 맵**(Ctrl+Alt+M)을 선택하고 다음 항목을 정합니다.

| 항목 | 설명 |
|---|---|
| 이름 | 파일 이름입니다. `resources/maps/<이름>.json`으로 저장됩니다 |
| 크기 (타일) | 가로, 세로 타일 개수 |
| 타일 크기 (px) | 타일 한 칸의 픽셀 크기 (보통 16이나 32) |
| 타일셋 | 프로젝트에 있는 PNG 중 하나 |
| 레이어 | 레이어 이름을 쉼표로 구분해 적습니다. 먼저 적은 레이어가 아래에 깔립니다 |

## 타일 칠하기

1. **팔레트**에서 타일을 클릭합니다. 드래그하면 여러 칸을 한꺼번에 고를 수 있습니다. 팔레트 위의 1x, 2x, 3x로 팔레트를 확대할 수 있습니다.
2. **레이어** 패널에서 칠할 레이어를 고릅니다. 지금 칠하는 레이어는 맵 뷰 위쪽의 "대상"에 표시됩니다.
3. 도구를 고르고 맵 위에 칠합니다.

| 도구 | 키 | 하는 일 |
|---|---|---|
| 펜 | B | 클릭하거나 드래그해서 칠하기 |
| 사각형 | R | 드래그한 사각형 영역 채우기 |
| 채우기 | G | 같은 타일로 이어진 영역을 한 번에 채우기 |
| 지우개 | E | 타일 지우기 |
| 스포이드 | I | 맵에 칠해진 타일을 팔레트에서 고른 것처럼 가져오기 |
| 통행 | C | 지나갈 수 없는 칸 정하기 (아래 설명 참고) |
| 오브젝트 | V | 맵 오브젝트 선택하고 옮기기 |

한 번 칠할 때마다 Ctrl+Z 한 번으로 되돌릴 수 있습니다.

## 화면 이동과 확대

| 조작 | 결과 |
|---|---|
| 마우스 휠 | 커서 위치를 중심으로 확대, 축소 |
| Shift+휠, 가운데 버튼 드래그, Space+드래그 | 화면 이동 |
| Ctrl+=, Ctrl+-, Ctrl+0 | 확대, 축소, 100% |
| 맵 전체 보기 (위쪽 버튼) | 맵 전체가 화면에 들어오게 맞추기 |

위쪽의 **격자**, **통행**, **오브젝트** 버튼으로 각각을 화면에 겹쳐 보거나 숨길 수 있습니다. **맵 > 위 레이어 흐리게**를 켜면 지금 칠하는 레이어보다 위에 있는 레이어가 흐려져서, 아래 레이어를 칠할 때 편합니다.

## 레이어

레이어 패널에서는 위쪽에 있는 레이어일수록 나중에, 즉 위에 그려집니다.

- **보임** 버튼으로 레이어를 맵 뷰에서 숨길 수 있습니다. 숨긴 레이어에는 칠할 수 없습니다.
- 이름을 두 번 클릭하면 바꿀 수 있습니다.
- 아래쪽 **추가**, **삭제**, **위로**, **아래로** 버튼으로 레이어를 관리합니다. 삭제도 되돌릴 수 있습니다.

## 통행

통행 도구(C)를 고른 뒤 왼쪽 버튼으로 칠하면 지나갈 수 없는 칸이 되고, 오른쪽 버튼으로 칠하면(또는 Alt를 누른 채 칠하면) 다시 지나갈 수 있는 칸이 됩니다. 막힌 칸은 위쪽 **통행** 버튼이나 **맵 > 통행 오버레이**로 확인합니다. 스크립트에서는 엔진의 `IsPassable`(Ruby는 `passable?`)로 읽습니다.

## 맵 오브젝트

몬스터, 시작 지점, 표지판처럼 맵 위에 놓이는 것들을 맵 오브젝트라고 합니다. 어떤 종류가 있고 종류마다 어떤 속성을 가지는지는 프로젝트의 `resources/schema/map-objects.json`에서 정합니다. 타일맵 템플릿에는 예시로 `marker` 하나만 들어 있으니, 필요한 종류를 이 파일에 추가해서 쓰면 됩니다.

```json
{
  "version": 1,
  "types": [
    { "type": "marker", "label": "표식", "shape": "point", "color": "accent",
      "fields": [{ "name": "label", "type": "string", "label": "이름" }] }
  ]
}
```

- **맵 오브젝트** 패널에서 종류별 추가 버튼을 눌러 만듭니다.
- 오브젝트 도구(V)로 선택하고 드래그해서 옮깁니다. 순찰 범위가 있는 오브젝트는 범위 끝의 손잡이도 드래그할 수 있습니다.
- 속성은 인스펙터에서 편집합니다. 꼭 채워야 하는 항목이 비어 있으면 검사 결과에 나옵니다.
- 복사, 붙여넣기, 복제(Ctrl+D), 삭제를 쓸 수 있습니다. 붙여넣은 오브젝트는 한 칸 오른쪽에 놓입니다.

## 맵 크기 바꾸기

**맵 > 크기 바꾸기**를 선택하거나 맵 뷰 위쪽의 크기 표시를 클릭합니다. 새 크기와 기준점(아홉 칸 중 하나)을 정하면, 기준점 쪽 내용은 그대로 두고 반대쪽을 늘리거나 잘라 냅니다. 맵 밖으로 밀려나는 오브젝트는 지우지 않고 알려 줍니다.

## 이 맵에서 바로 실행하기

맵 탭에서 **맵 > 이 맵에서 실행**(Ctrl+F5)을 선택하면 지금 맵에서 게임을 시작합니다.

- 오브젝트를 하나 선택해 두었다면 그 위치에서, 아니면 커서 위치나 화면 가운데에서 시작합니다.
- 엔진을 어떻게 실행할지는 맵 오브젝트 파일의 `play` 항목이 정합니다. 이 기능을 지원하지 않는 맵이라면 실행하지 않고 이유를 알려 줍니다.

## 씬에서 맵 보여 주기

게임 화면에 맵을 보여 주려면 씬에 타일맵 오브젝트를 추가하고 맵 파일을 고르면 됩니다 ([씬 편집](scenes.md#타일맵-오브젝트)). 타일맵 템플릿으로 만든 프로젝트는 이미 연결되어 있어서, 맵을 칠하고 저장한 뒤 F5만 누르면 바로 확인할 수 있습니다.

## 저장 형식

저장(Ctrl+S)하면 엔진이 읽는 형식 그대로 저장됩니다. 맵의 타일 한 줄이 파일에서도 한 줄이라 git에서 어느 칸이 바뀌었는지 알아보기 쉽고, 에디터가 모르는 항목도 지우지 않고 그대로 둡니다.
