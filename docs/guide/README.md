# InitialEditor 사용자 가이드

InitialEditor는 Initial2D 엔진으로 2D 게임을 만드는 에디터입니다. 씬과 맵을 화면에서 편집하고, Lua나 Ruby로 게임 로직을 작성하고, F5로 바로 실행해 확인합니다. 플래피버드 같은 작은 아케이드 게임부터 맵과 이벤트가 있는 RPG까지 같은 도구로 만듭니다.

![맵 편집 화면](images/map-editor.png)

## 처음이라면

순서대로 읽으면 30분 안에 프로젝트를 만들어 실행하고, 오브젝트 하나를 직접 움직여 볼 수 있습니다.

1. [설치와 첫 실행](install.md): 데스크톱 앱을 받아 설치합니다. 설치 없이 브라우저에서 쓰는 웹판도 있습니다.
2. [첫 프로젝트](first-project.md): 템플릿으로 프로젝트를 만들고 F5로 실행합니다.
3. [화면 구성](interface.md): 패널, 문서 탭, 레이아웃, 설정의 위치를 익힙니다.
