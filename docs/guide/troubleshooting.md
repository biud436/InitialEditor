# 문제 해결

각 항목은 증상, 원인, 해결 방법 순서로 설명합니다.

## 설치와 시작

**처음 실행할 때 운영체제가 앱을 차단합니다.**
원인: 앱에 코드 서명이 되어 있지 않습니다.
해결: [설치와 첫 실행](install.md#실행이-차단되는-경우)의 운영체제별 방법을 따릅니다.

**웹판에서 폴더 열기 버튼이 비활성화되어 있습니다.**
원인: 브라우저가 File System Access API를 지원하지 않습니다(Safari, Firefox).
해결: Chrome 또는 Edge를 사용합니다.

**웹판 샘플 프로젝트에서 변경한 내용이 사라졌습니다.**
원인: 샘플 프로젝트는 브라우저 메모리에만 존재하고, 페이지를 새로 고치면 사라집니다.
해결: **새 프로젝트**로 컴퓨터의 폴더에 프로젝트를 만들어 작업합니다.

## 실행

**F5를 누르면 별도 창이 아니라 게임 탭에서 실행됩니다.**
원인: 실행 방식이 게임 탭으로 설정되어 있거나, 엔진 실행 파일을 찾지 못했습니다. Windows 판에는 엔진 실행 파일이 포함되어 있지 않습니다.
해결: 상태 표시줄의 엔진 항목과 **도구 > 설정**의 **찾은 엔진**을 확인합니다. [엔진 탐색](running.md#엔진-탐색-데스크톱-앱) 순서를 참고합니다.

**엔진 실행 허용 확인 창에서 거부했습니다.**
해결: **도구 > 설정**의 **찾은 엔진**에서 **다시 묻기**를 누릅니다.

**Ruby 프로젝트가 실행되지 않습니다.**
원인: 엔진에 mruby가 포함되어 있지 않습니다.
해결: 앱에 포함된 엔진이나 웹판 엔진을 사용합니다. 엔진 경로를 직접 지정했다면 `--features` 출력에 `mruby`가 있는지 확인합니다.

**게임이 시작하자마자 종료됩니다.**
원인: 시작 과정이나 `update`, `render`에서 스크립트 오류가 발생했습니다.
해결: 콘솔에서 `Lua error` 또는 `mruby:`로 시작하는 줄을 찾아 클릭합니다. 오류 위치가 열립니다. 메시지가 `scene:`으로 시작하면 씬 파일이나 씬에서 참조하는 파일(이미지, 맵, 매개변수 선언)의 문제입니다.

**저장한 내용이 게임에 반영되지 않습니다.**
원인과 해결:
- 게임이 실행 중이 아니었습니다. 실행 중이 아닐 때 저장한 내용은 다음 실행에 반영됩니다.
- **도구 > 설정**의 **저장 시 리로드**가 꺼져 있습니다.
- 게임이 오류로 종료되었습니다. F5로 다시 실행합니다.
- 비주얼 스크립팅 그래프에 오류가 있어 코드가 생성되지 않았습니다. 그래프 편집기 위쪽의 상태를 확인합니다.

**저장하면 게임이 처음 장면으로 돌아갑니다.**
원인: 핫 리로드는 스크립트 실행 환경을 다시 만들고 시작 씬부터 다시 실행합니다. [핫 리로드](running.md#핫-리로드)를 참고합니다.

**게임 탭에서 소리가 나지 않습니다.**
원인: 브라우저는 사용자가 페이지를 조작하기 전에는 소리를 재생하지 않습니다.
해결: 게임 탭 위쪽의 **소리 켜기**를 누르거나 게임 화면을 클릭합니다.

**효과음이 재생되지 않습니다.**
원인과 해결:
- 파일 경로가 폴더이거나 파일이 없습니다. 경로에 파일 이름과 확장자를 포함합니다 (`./resources/audio/flap.wav`).
- 파일 형식이 MP3입니다. WAV 또는 OGG로 변환합니다.
- Lua에서 `loop` 인자를 생략했습니다. 세 인자를 모두 지정합니다.
- 효과음 8개가 이미 재생 중입니다. 매 틱 재생하지 않도록 조건을 확인합니다.

자세한 내용은 [소리](audio.md)를 참고합니다.

**다른 효과음 파일을 지정했는데 처음 효과음이 재생됩니다.**
원인: 소리는 `id`로 구분되며, 같은 `id`로 이미 읽은 소리가 있으면 파일 경로를 무시합니다.
해결: 파일마다 다른 `id`를 사용합니다.

**게임 탭에서 키 입력이 동작하지 않습니다.**
해결: 게임 화면을 클릭해 입력이 게임으로 전달되게 합니다.

**키를 누르고 있는 동안의 동작이 한 틱 늦게 시작됩니다.**
원인: `IsKeyPress`는 키를 누른 첫 틱에 거짓입니다.
해결: `IsKeyDown(key) or IsKeyPress(key)`로 판정합니다. [입력](input.md)을 참고합니다.

**씬 뷰와 실행 화면이 다릅니다.**
원인: 씬 뷰는 씬 파일의 초기 상태만 표시합니다. 컴포넌트가 실행 중에 바꾸는 내용은 표시되지 않습니다.
해결: **현재 씬부터 실행**(Ctrl+F5)으로 확인합니다.

**이미지의 투명한 부분이 색으로 표시됩니다.**
원인: 이미지에 알파 채널이 없습니다(RGB PNG, JPG). 엔진은 특정 색을 투명색으로 처리하지 않습니다.
해결: 투명할 부분의 알파 값을 0으로 만든 RGBA PNG로 저장합니다. [이미지와 텍스트 출력](graphics.md#2-알파-채널)을 참고합니다.

**텍스트의 일부 글자가 표시되지 않습니다.**
원인: 글꼴 파일에 그 글자가 없습니다. 템플릿 글꼴은 KS X 1001 완성형 2,350자만 포함합니다.
해결: 필요한 글자를 포함한 BMFont 글꼴을 만들어 `resources/fonts/`에 넣고 `props.font`로 지정합니다.

**텍스트가 있는 씬이 느립니다.**
원인: 한 씬에서 서로 다른 글꼴을 쓰는 텍스트가 있으면 매 프레임 글꼴 파일을 다시 읽습니다.
해결: 한 씬에서는 글꼴 하나만 사용합니다.

**인스펙터에 "씬 로더 교체" 안내가 표시됩니다.**
원인: 프로젝트의 씬 로더 파일이 매개변수를 컴포넌트에 전달하지 않는 버전입니다.
해결: **씬 로더 교체**를 누릅니다. 씬 로더 파일을 직접 수정했다면 교체하기 전에 백업합니다. 교체하면 그 수정 내용은 사라집니다.

## 스크립트

**자동 완성이 표시되지 않거나 언어 서버가 응답하지 않습니다.**
해결: **도구 > 언어 서버 다시 시작**을 선택합니다. **도구 > 설정**에서 **언어 서버**가 켜져 있는지 확인합니다.

**엔진 함수의 자동 완성이 일부만 표시됩니다.**
원인: 프로젝트에 `resources/api/initial2d-api.json`이 없어 에디터에 포함된 기본 정의를 사용하고 있습니다.
해결: 템플릿으로 만든 프로젝트에서 이 파일을 복사합니다.

**진단 경고가 너무 많습니다.**
해결: **도구 > 설정**의 **진단 표시**를 **구문 오류만**으로 바꾸거나, 프로젝트의 `.luarc.json`에서 규칙을 끕니다.

**다른 프로그램에서 수정한 내용과 에디터의 내용이 다릅니다.**
원인: 편집 중인 파일이 외부에서 변경되었습니다.
해결: 편집기 위쪽 알림에서 유지할 내용을 선택합니다. 저장 시점에 디스크의 파일이 변경되어 있으면 덮어쓰기, 다시 읽기, 취소 중에서 선택합니다.

## 맵과 이벤트

**레이어 패널에 이벤트 레이어가 없습니다.**
원인: 이벤트는 `resources/data/rpg-game.json`에 등록된 맵에서만 편집할 수 있습니다.
해결: RPG 데모 프로젝트에서 맵을 `rpg-game.json`의 맵 목록에 등록합니다.

**이 맵에서 실행이 동작하지 않습니다.**
원인: 맵 오브젝트 스키마(`resources/schema/map-objects.json`)에 `play` 항목이 없거나, `play.maps` 패턴이 이 맵 이름과 일치하지 않습니다.
해결: 콘솔과 알림에 표시된 이유를 확인합니다.

**배치한 타일이 다른 타일로 바뀌어 보입니다.**
원인: 타일셋 이미지에서 타일 위치나 가로 타일 수가 바뀌었습니다. 맵은 타일을 이미지 안의 위치로 계산한 번호로 저장합니다.
해결: 타일셋 이미지를 이전 배열로 되돌리고, 새 타일은 이미지 아래쪽에 추가합니다. [맵](maps.md#타일-번호)을 참고합니다.

## 화면

**패널이 사라졌거나 배치가 바뀌었습니다.**
해결: **창** 메뉴에서 패널을 다시 열거나 **창 > 레이아웃 초기화**를 선택합니다.
