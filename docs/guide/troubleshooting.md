# 문제 해결

## 설치와 시작

**앱을 처음 열 때 운영체제가 막습니다.**
아직 코드 서명이 없어서입니다. [설치와 첫 실행](install.md#처음-열-때-차단되면)의 운영체제별 방법을 따릅니다.

**웹판에서 폴더 열기 버튼이 꺼져 있습니다.**
폴더 열기는 Chrome과 Edge에서만 됩니다. Safari나 Firefox에서는 샘플 프로젝트로만 시작합니다.

**웹판 샘플에서 바꾼 내용이 사라졌습니다.**
샘플 프로젝트는 브라우저 메모리에만 있어서 페이지를 다시 열면 처음 상태로 돌아갑니다. 작업을 남기려면 **새 프로젝트**로 컴퓨터의 폴더에 만듭니다.

## 실행

**F5를 눌러도 별도 창이 뜨지 않고 게임 탭에서 실행됩니다.**
엔진 실행 파일을 찾지 못했거나, 설정의 실행 방식이 게임 탭입니다. 상태 바의 엔진 칸과 **도구 > 설정**의 **찾은 엔진** 줄을 확인합니다. Windows 판은 엔진 실행 파일이 없어 항상 게임 탭에서 실행됩니다.

**엔진 실행을 허용할지 묻는 창에서 거부했습니다.**
**도구 > 설정**의 **찾은 엔진** 줄에서 **다시 묻기**를 누릅니다.

**Ruby 프로젝트가 실행되지 않습니다.**
엔진 빌드에 mruby가 들어 있어야 합니다. 앱에 든 엔진과 웹판의 엔진에는 들어 있습니다. 직접 지정한 엔진이라면 `--features` 출력에 `mruby`가 있는지 확인합니다.

**게임이 바로 꺼집니다.**
콘솔에서 `Lua error` 또는 `mruby:`로 시작하는 줄을 찾아 누릅니다. 오류가 난 줄로 이동합니다. 시작할 때나 `update`, `render`에서 난 오류는 게임을 종료 코드 1로 끝냅니다.

**저장했는데 게임에 반영되지 않습니다.**
- 게임이 실행 중인지 확인합니다. 실행 중이 아닐 때 저장한 것은 다음 실행에 반영됩니다.
- **도구 > 설정**의 **저장 시 리로드**가 켜져 있는지 확인합니다.
- 오류로 끝난 게임에는 반영되지 않습니다. F5로 다시 실행합니다.

**게임 탭에서 소리가 나지 않습니다.**
브라우저는 사용자가 누르기 전에는 소리를 내지 않습니다. 게임 탭 위쪽의 **소리 켜기**나 게임 화면을 한 번 누릅니다.

**게임 탭에서 키 입력이 게임에 가지 않습니다.**
게임 화면을 한 번 누르면 키 입력이 게임으로 갑니다.

**씬 뷰와 실제 게임 화면이 다릅니다.**
씬 뷰는 파일에 적힌 처음 상태만 보여 줍니다. 컴포넌트가 움직이거나 그리는 것은 실행해야 보입니다 (Ctrl+F5).

**인스펙터에 "씬 로더 교체" 안내가 나옵니다.**
매개변수가 생기기 전에 만든 프로젝트의 씬 로더는 매개변수를 넘기지 못합니다. **씬 로더 교체**를 누르면 에디터에 든 새 로더로 바뀝니다. 로더 파일을 직접 편집했다면 그 변경은 사라지므로 먼저 백업합니다.

## 스크립트

**자동 완성이 나오지 않거나 언어 서버가 멈췄습니다.**
**도구 > 언어 서버 다시 시작**을 선택합니다. **도구 > 설정**의 **언어 서버**가 켜져 있는지도 확인합니다.

**엔진 함수의 자동 완성이 일부만 나옵니다.**
프로젝트에 `resources/api/initial2d-api.json`이 없으면 앱에 든 기본 정보로 동작합니다. 템플릿으로 만든 프로젝트에는 들어 있습니다.

**경고 밑줄이 너무 많습니다.**
**도구 > 설정**의 **진단 표시**를 **구문 오류만**으로 바꾸거나, 프로젝트의 `.luarc.json`에서 규칙을 끕니다.

**다른 프로그램에서 편집한 내용과 에디터의 내용이 다릅니다.**
편집 중인 파일이 밖에서 바뀌면 위쪽 알림 띠에서 어느 쪽을 남길지 선택합니다. 저장할 때 디스크의 파일이 바뀌어 있으면 덮어쓰기, 다시 읽기, 취소 중에서 선택합니다.

## 맵과 이벤트

**맵의 레이어 패널에 이벤트 줄이 없습니다.**
RPG 데모로 만든 프로젝트에서, `resources/data/rpg-game.json`에 등록된 맵만 이벤트를 편집할 수 있습니다.

**이 맵에서 실행이 되지 않습니다.**
맵 오브젝트 스키마(`resources/schema/map-objects.json`)의 `play` 항목이 이 맵을 지원하지 않는 경우입니다. 이유가 콘솔과 알림에 표시됩니다.

## 화면

**패널이 사라졌거나 배치가 엉켰습니다.**
**창** 메뉴에서 패널을 다시 열거나, **창 > 레이아웃 초기화**를 선택합니다.

## 그래도 해결되지 않으면

[GitHub 이슈](https://github.com/biud436/InitialEditor/issues)에 남겨 주십시오. **도움말 > InitialEditor 정보**의 버전과 운영체제, 콘솔의 오류 줄을 함께 적어 주시면 원인을 찾기 쉽습니다.
