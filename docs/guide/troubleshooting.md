# 문제 해결

## 설치와 시작

**앱을 처음 열 때 운영체제가 실행을 막습니다.**
아직 코드 서명을 하지 않아서 생기는 일입니다. [설치와 첫 실행](install.md#처음-실행이-막힐-때)에서 운영체제별 해결 방법을 확인하세요.

**웹판에서 폴더 열기 버튼을 누를 수 없습니다.**
폴더 열기는 Chrome과 Edge에서만 지원합니다. Safari나 Firefox에서는 샘플 프로젝트로만 시작할 수 있습니다.

**웹판 샘플에서 고친 내용이 사라졌습니다.**
샘플 프로젝트는 브라우저 메모리에만 있어서 페이지를 다시 열면 처음 상태로 돌아갑니다. 작업한 내용을 남기려면 **새 프로젝트**로 내 컴퓨터 폴더에 프로젝트를 만드세요.

## 실행

**F5를 눌렀는데 별도 창이 아니라 게임 탭에서 실행됩니다.**
엔진 실행 파일을 찾지 못했거나, 설정에서 실행 방식이 게임 탭으로 되어 있는 경우입니다. 상태 바의 엔진 항목과 **도구 > 설정**의 **찾은 엔진**을 확인해 보세요. Windows 판은 엔진 실행 파일이 없어서 언제나 게임 탭에서 실행됩니다.

**엔진 실행을 허용할지 묻는 창에서 거부를 눌렀습니다.**
**도구 > 설정**의 **찾은 엔진**에서 **다시 묻기**를 누르세요.

**Ruby 프로젝트가 실행되지 않습니다.**
엔진에 mruby가 포함되어 있어야 합니다. 앱에 들어 있는 엔진과 웹판 엔진에는 포함되어 있습니다. 엔진을 직접 지정했다면 `--features`로 실행했을 때 `mruby`가 나오는지 확인하세요.

**게임이 켜지자마자 꺼집니다.**
콘솔에서 `Lua error`나 `mruby:`로 시작하는 줄을 찾아 클릭하면 오류가 난 곳으로 이동합니다. 시작할 때나 `update`, `render`에서 오류가 나면 게임은 종료 코드 1로 끝납니다.

**저장했는데 게임에 적용되지 않습니다.**
- 게임이 실행 중인지 확인하세요. 실행 중이 아닐 때 저장한 내용은 다음에 실행할 때 적용됩니다.
- **도구 > 설정**에서 **저장 시 리로드**가 켜져 있는지 확인하세요.
- 오류로 끝난 게임에는 적용되지 않습니다. F5로 다시 실행하세요.

**게임 탭에서 소리가 나지 않습니다.**
브라우저는 사용자가 무언가를 누르기 전까지 소리를 내지 않습니다. 게임 탭 위쪽의 **소리 켜기**를 누르거나 게임 화면을 한 번 클릭하세요.

**효과음이 나지 않습니다.**
효과음 재생 노드의 **파일 경로**에는 파일 이름까지 적어야 합니다 (`./resources/audio/flap.wav`). 폴더 경로(`./resources/audio/`)만 적으면 엔진이 파일을 읽지 못해 소리가 나지 않기 때문에, 그래프가 오류로 알려 줍니다. **이름**은 비워 두면 파일 경로를 이름으로 씁니다.

**게임 탭에서 키를 눌러도 반응이 없습니다.**
게임 화면을 한 번 클릭하면 키 입력이 게임으로 전달됩니다.

**씬 뷰와 실제 게임 화면이 다릅니다.**
씬 뷰는 파일에 저장된 처음 상태만 보여 줍니다. 컴포넌트가 오브젝트를 움직이거나 그리는 모습은 실행해야 볼 수 있습니다 (Ctrl+F5).

**인스펙터에 "씬 로더 교체" 안내가 나옵니다.**
매개변수 기능이 생기기 전에 만든 프로젝트라서, 씬 로더가 매개변수를 넘겨주지 못하는 상태입니다. **씬 로더 교체**를 누르면 에디터에 들어 있는 새 로더로 바뀝니다. 로더 파일을 직접 고친 적이 있다면 그 내용은 사라지니 먼저 백업해 두세요.

## 스크립트

**자동 완성이 안 나오거나 언어 서버가 멈췄습니다.**
**도구 > 언어 서버 다시 시작**을 선택하세요. **도구 > 설정**에서 **언어 서버**가 켜져 있는지도 확인하세요.

**엔진 함수가 자동 완성에 일부만 나옵니다.**
프로젝트에 `resources/api/initial2d-api.json`이 없으면 앱에 들어 있는 기본 정보를 씁니다. 템플릿으로 만든 프로젝트에는 이 파일이 들어 있습니다.

**경고 밑줄이 너무 많습니다.**
**도구 > 설정**의 **진단 표시**를 **구문 오류만**으로 바꾸거나, 프로젝트의 `.luarc.json`에서 원하지 않는 규칙을 끄세요.

**다른 프로그램에서 고친 내용과 에디터 내용이 다릅니다.**
편집 중인 파일이 바깥에서 바뀌면, 위쪽 알림에서 어느 쪽 내용을 남길지 고를 수 있습니다. 저장하는 순간 디스크의 파일이 바뀌어 있었다면 덮어쓰기, 다시 불러오기, 취소 중에서 고르게 됩니다.

## 맵과 이벤트

**맵 레이어 패널에 이벤트 레이어가 없습니다.**
이벤트는 RPG 데모로 만든 프로젝트에서, `resources/data/rpg-game.json`에 등록된 맵에서만 편집할 수 있습니다.

**이 맵에서 실행이 되지 않습니다.**
맵 오브젝트 파일(`resources/schema/map-objects.json`)의 `play` 항목이 이 맵을 지원하지 않는 경우입니다. 이유는 콘솔과 알림에 나옵니다.

## 화면

**패널이 사라졌거나 배치가 엉망이 되었습니다.**
**창** 메뉴에서 패널을 다시 열거나 **창 > 레이아웃 초기화**를 선택하세요.

## 그래도 해결되지 않는다면

[GitHub 이슈](https://github.com/biud436/InitialEditor/issues)에 남겨 주세요. **도움말 > InitialEditor 정보**에 나오는 버전, 사용하는 운영체제, 콘솔의 오류 메시지를 함께 적어 주시면 원인을 찾는 데 큰 도움이 됩니다.
