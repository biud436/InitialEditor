# RPG 이벤트

RPG 데모 템플릿으로 만든 프로젝트에서는 맵 위에 이벤트를 배치해 NPC 대화, 상자, 맵 이동 같은 것을 만듭니다. 이벤트는 맵 파일의 `events`에 저장되고, 게임의 RPG 레이어(`scripts/lua/rpg/`)가 실행합니다. RPG 레이어가 Lua로 되어 있어 RPG 프로젝트는 Lua 전용입니다.

![이벤트 편집](images/rpg-events.png)

## 이벤트를 쓸 수 있는 맵

`resources/data/rpg-game.json`에 등록된 맵(데모에서는 항구 마을과 여관)을 열면 레이어 패널 맨 위에 **이벤트** 줄이 생깁니다. 등록되지 않은 맵에는 이벤트 줄 대신 안내가 표시됩니다. 새 맵에서 이벤트를 쓰려면 `rpg-game.json`의 맵 목록에 그 맵을 더합니다.

## 이벤트 만들기와 배치

1. **맵 > 이벤트 도구**(N)를 선택합니다.
2. 빈 칸을 두 번 누르면 그 칸에 새 이벤트가 생깁니다.
3. 오른쪽 인스펙터에서 속성과 커맨드를 편집합니다.

| 조작 | 결과 |
|---|---|
| 클릭 | 선택 (Shift, Ctrl과 함께 누르면 더하기와 빼기) |
| 빈 곳에서 끌기 | 상자 선택 |
| 이벤트 끌기 | 칸 단위로 이동. 놓을 수 없는 칸이면 빨간 미리보기가 표시되고 제자리로 돌아갑니다 |
| 방향키 | 한 칸 이동 |
| Delete | 삭제 |
| Enter | 커맨드 편집으로 이동 |
| Ctrl+C, Ctrl+V, Ctrl+D | 복사, 커서 칸에 붙여넣기, 복제 |

외형이 있는 이벤트는 캐릭터 그림으로, 외형이 없는 이벤트는 칸에 트리거의 첫 글자(말, 밟, 자, 병)로 표시됩니다.

## 이벤트 속성

| 속성 | 설명 |
|---|---|
| id | 이벤트 이름. 이동 루트와 방향 전환 커맨드가 이 id로 이벤트를 가리킵니다. 바꾸면 이 맵 안의 참조도 함께 바뀝니다 |
| x, y | 칸 위치 |
| 방향 | 처음 바라보는 방향 |
| 트리거 | 언제 실행되는가 (아래 표) |
| 외형 | 캐릭터 그림. 아래 8칸 격자에서 선택합니다 |
| 통행 가능, 통행 막기 | 플레이어가 지나갈 수 있는가 |
| 속도, 배회 | 이동 속도와 돌아다니는 범위. 배회 구역의 가장자리는 맵에서 끌어 조절합니다 |

| 트리거 | 실행되는 때 |
|---|---|
| action (말) | 플레이어가 앞에서 결정 키를 누를 때. NPC 대화, 상자 |
| touch (밟) | 플레이어가 그 칸에 올라설 때. 문, 함정 |
| auto (자) | 맵에 들어오면 자동으로 한 번. 컷신 |
| parallel (병) | 맵에 있는 동안 계속. 배경 연출 |

## 커맨드 편집

인스펙터 아래의 커맨드 목록이 이벤트가 실행할 내용입니다. 위에서 아래로 차례로 실행됩니다.

| 키 | 동작 |
|---|---|
| 위, 아래 | 줄 이동 |
| Enter | 그 커맨드의 입력 폼 열기 |
| Insert | 커맨드 목록(팔레트)을 열어 새 커맨드 넣기 |
| Ctrl+위, Ctrl+아래 | 커맨드 순서 바꾸기 |
| Ctrl+C, Ctrl+V | 여러 줄 복사와 붙여넣기 |
| Delete | 커맨드 빼기 |
| Esc | 입력 폼에서 목록으로 돌아가기 |

목록 위의 **위에 삽입**, **아래에 삽입** 버튼으로도 커맨드를 넣습니다. Insert 키가 없는 macOS 키보드에서는 이 버튼이나, 목록 끝 줄에서 Enter를 씁니다.

쓸 수 있는 커맨드는 다음과 같습니다.

| 분류 | 커맨드 |
|---|---|
| 대화 | 대화, 선택지, 장소 이름 |
| 흐름 | 조건 분기, 기다리기, 메모 |
| 이동 | 맵 이동, 이동 루트, 방향 전환 |
| 상태 | 플래그, 변수, 아이템 얻기, 아이템 잃기 |
| 소리 | 효과음, 배경음 |
| 그 밖 | 씬 전환, 스크립트 |

조건 분기는 아이템 개수, 플래그 값 같은 조건으로 커맨드를 나눕니다. 데모의 대사 대부분이 플래그와 아이템에 따라 달라집니다.

### 맵 이동의 위치 지정

맵 이동 커맨드의 폼 아래에 **맵에서 선택**과 **대상 보기** 버튼이 있습니다.

- **맵에서 선택**: 대상 맵이 열립니다. 도착할 타일을 누르면 원래 맵으로 돌아오고 x, y가 채워집니다. Esc로 취소합니다.
- **대상 보기**: 대상 맵을 열고 지정한 칸을 화면 가운데에 보여 줍니다.

## 이벤트 패널

**창 > 이벤트**(타일맵 레이아웃에 포함)는 이 맵의 이벤트 목록입니다. id, 트리거, 대사로 찾을 수 있고, 오류와 경고 수가 표시됩니다.

패널 위쪽의 **시작 상태** 칸에 플래그와 아이템을 적어 두면, 실행할 때 그 상태로 게임을 시작합니다. 예를 들어 `arrived,item:warehouse_key=1`은 `arrived` 플래그를 켜고 창고 열쇠 한 개를 가진 상태입니다. 비우면 새 게임 그대로입니다. 대사가 상태에 따라 달라지는 이벤트를 확인할 때 씁니다.

## 바로 실행해 확인하기

| 방법 | 결과 |
|---|---|
| 이 맵에서 실행 (Ctrl+F5) | 선택한 이벤트 앞 칸, 아니면 커서 칸이나 화면 가운데에 가장 가까운 설 수 있는 칸에서 시작 |
| 이 이벤트 앞에서 실행 | 이벤트 앞 칸에 이벤트를 바라보고 서서 시작. 직접 말을 걸어 봅니다 |
| 이 이벤트 자동 재생 | 플레이어가 알아서 말을 걸거나 밟고, 대화를 넘기고(선택지는 첫 항목), 끝나면 게임이 닫힙니다 |

뒤의 둘은 인스펙터의 **앞에서 실행**, **자동 재생** 버튼, **맵** 메뉴, 이벤트 패널 줄의 오른쪽 클릭 메뉴에 있습니다. parallel 이벤트는 끝나지 않으므로 자동 재생을 쓸 수 없습니다.

콘솔에는 플레이어 위치(`rpg:player:`), 실행된 이벤트(`rpg:event:`), 표시된 대사(`rpg:message:`) 줄이 남아 무엇이 실행되었는지 확인할 수 있습니다.

## 저장할 때 오류가 있으면

다른 프로그램에서 맵 파일을 편집해 엔진이 건너뛸 이벤트가 생겼다면, 저장하기 전에 그 목록을 보여 주고 묻습니다. 에디터 안에서 편집한 값은 이런 오류를 만들지 않습니다.
