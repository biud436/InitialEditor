# RPG 이벤트

이벤트는 맵 위의 한 칸에 배치하는 실행 단위입니다. 트리거 조건과 커맨드 목록을 가지며, 트리거 조건이 충족되면 커맨드를 위에서부터 순서대로 실행합니다. 이벤트는 맵 파일의 `events`에 저장되고, 게임의 RPG 스크립트(`scripts/lua/rpg/`)가 읽어 실행합니다. 엔진 자체는 이벤트를 읽지 않습니다.

RPG 데모 템플릿으로 만든 프로젝트에서 사용할 수 있습니다. RPG 스크립트가 Lua로 작성되어 있으므로 Lua 프로젝트에서만 동작합니다.

![이벤트 편집](images/rpg-events.png)

## 이벤트를 편집할 수 있는 맵

`resources/data/rpg-game.json`의 맵 목록에 등록된 맵에서만 이벤트를 편집할 수 있습니다. 등록된 맵을 열면 레이어 패널 맨 위에 **이벤트** 레이어가 표시됩니다. 등록되지 않은 맵에는 이벤트 레이어 대신 안내 문구가 표시됩니다.

> **주의**: 같은 맵의 파일이 두 개 등록된 경우(예: RTP 소재용과 기본 소재용)와 이벤트 스키마 버전을 알 수 없는 경우, 이벤트 레이어는 읽기 전용입니다. 이유는 레이어 이름 옆에 표시됩니다.

## 이벤트 만들기와 배치

1. **맵 > 이벤트 도구**(N)를 선택합니다.
2. 빈 칸을 두 번 클릭하면 그 칸에 이벤트가 만들어집니다.
3. 인스펙터에서 속성과 커맨드를 편집합니다.

| 조작 | 동작 |
|---|---|
| 클릭 | 선택. Shift 또는 Ctrl과 함께 누르면 선택에 추가하거나 제외 |
| 빈 곳에서 드래그 | 사각형 영역 안의 이벤트 선택 |
| 이벤트 드래그 | 칸 단위로 이동. 배치할 수 없는 칸이면 빨간색으로 표시하고 원래 위치로 되돌림 |
| 방향키 | 한 칸 이동 |
| Delete | 삭제 |
| Enter | 커맨드 목록으로 이동 |
| Ctrl+C, Ctrl+V, Ctrl+D | 복사, 커서 위치의 칸에 붙여넣기, 복제 |

외형이 지정된 이벤트는 캐릭터 이미지로, 외형이 없는 이벤트는 트리거의 첫 글자(말, 밟, 자, 병)로 표시됩니다.

## 이벤트 속성

| 속성 | 정의 |
|---|---|
| id | 맵 안에서 고유한 이벤트 이름입니다. 이동 루트, 방향 전환 커맨드가 이 값으로 이벤트를 지정합니다 |
| x, y | 타일 좌표 (0부터) |
| 방향 | 처음 바라보는 방향 (down, left, right, up) |
| 트리거 | 커맨드를 실행하는 조건 (아래 표) |
| 외형 | 캐릭터 이미지와 그 안의 캐릭터 위치 (8칸 중 선택) |
| 외형이 있어도 통행 가능 | 켜면 외형이 있어도 플레이어가 지나갈 수 있습니다 |
| 통행 막기 | 플레이어의 통행을 막을지 지정합니다. 지정하지 않으면 외형이 있을 때 막습니다 |
| 속도 | 이동 속도(타일/초, 기본 3) |
| 배회 | 이벤트가 무작위로 이동하는 범위 |

| 트리거 | 실행 조건 |
|---|---|
| action (말) | 플레이어가 이벤트 앞에서 결정 키를 누를 때 |
| touch (밟) | 플레이어가 이벤트 칸에 들어설 때 |
| auto (자) | 맵에 들어갈 때 한 번 |
| parallel (병) | 맵에 있는 동안 반복 |

> **주의**: id를 바꾸면 같은 맵 안의 이동 루트, 방향 전환 커맨드가 가리키는 id도 함께 바뀝니다. 다른 맵이나 스크립트에서 그 id를 참조하는 곳은 바뀌지 않습니다.

> **주의**: `player`는 플레이어를 가리키는 예약된 이름이므로 이벤트 id로 쓸 수 없습니다.

## 커맨드

커맨드는 이벤트가 실행하는 동작 하나입니다. 커맨드 목록은 위에서부터 순서대로 실행됩니다.

| 분류 | 커맨드 |
|---|---|
| 대화 | 대화, 선택지, 장소 이름 |
| 흐름 | 조건 분기, 기다리기, 메모 |
| 이동 | 맵 이동, 이동 루트, 방향 전환 |
| 상태 | 플래그, 변수, 아이템 얻기, 아이템 잃기 |
| 소리 | 효과음, 배경음 |
| 그 밖 | 씬 전환, 스크립트 |

- 조건 분기는 아이템 개수, 플래그 값 같은 조건에 따라 다른 커맨드를 실행합니다.
- 메모는 실행되지 않는 설명 줄입니다.
- 아이템 잃기는 아이템이 부족하면 실행되지 않습니다.

### 커맨드 목록 조작

| 키 | 동작 |
|---|---|
| 위, 아래 | 줄 이동 |
| Enter | 커맨드 인자 입력란 열기 |
| Insert | 커맨드 종류 목록을 열어 새 커맨드 삽입 |
| Ctrl+위, Ctrl+아래 | 커맨드 순서 변경 |
| Ctrl+C, Ctrl+V | 여러 줄 복사, 붙여넣기 |
| Delete | 커맨드 삭제 |
| Esc | 입력란에서 목록으로 돌아가기 |

목록 위의 **위에 삽입**, **아래에 삽입** 버튼으로도 커맨드를 삽입합니다. Insert 키가 없는 키보드에서는 이 버튼을 쓰거나 목록 마지막 줄에서 Enter를 누릅니다.

### 맵 이동 커맨드의 도착 위치

맵 이동 커맨드의 입력란 아래에 **맵에서 선택**과 **대상 보기** 버튼이 있습니다.

- **맵에서 선택**: 도착할 맵을 엽니다. 타일을 클릭하면 원래 맵으로 돌아오고 x, y 값이 입력됩니다. Esc를 누르면 취소합니다.
- **대상 보기**: 도착할 맵을 열고 지정된 칸을 화면 가운데에 표시합니다.

## 이벤트 패널

**창 > 이벤트**는 현재 맵의 이벤트 목록을 표시합니다. id, 트리거, 대사로 검색할 수 있고, 오류와 경고 수가 표시됩니다.

**시작 상태**는 실행할 때 미리 설정할 플래그와 아이템입니다. 형식은 쉼표로 구분한 목록이며, 플래그 이름은 켜진 플래그, `item:<아이템>=<개수>`는 보유 아이템입니다. 예를 들어 `arrived,item:warehouse_key=1`은 `arrived` 플래그가 켜지고 `warehouse_key` 아이템을 1개 가진 상태입니다. 비워 두면 새 게임 상태입니다. 시작 상태는 맵별로 `.initial-editor/rpg-play.json`에 저장됩니다.

## 실행해서 확인하기

| 명령 | 시작 위치와 동작 |
|---|---|
| 이 맵에서 실행 (Ctrl+F5) | 선택한 이벤트의 앞 칸, 또는 커서나 화면 가운데에서 가장 가까운 이동 가능한 칸에서 시작합니다 |
| 이 이벤트 앞에서 실행 | 이벤트의 앞 칸에서 이벤트를 바라본 상태로 시작합니다 |
| 이 이벤트 자동 재생 | 플레이어가 이벤트를 자동으로 실행하고(결정 키, 이동, 맵 진입), 대화를 넘기고(선택지는 첫 항목), 끝나면 게임을 종료합니다 |

**앞에서 실행**과 **자동 재생**은 인스펙터의 버튼, **맵** 메뉴, 이벤트 패널의 오른쪽 클릭 메뉴에서 실행합니다. 콘솔에는 플레이어 위치(`rpg:player:`), 실행된 이벤트(`rpg:event:`), 표시된 대사(`rpg:message:`)가 출력됩니다.

> **주의**: parallel 이벤트는 끝나지 않으므로 자동 재생할 수 없습니다.

> **주의**: 맵에 auto 이벤트가 있으면, 자동 재생 대상 이벤트보다 먼저 실행될 수 있습니다. 그동안 배회하는 이벤트가 자리를 옮기면 자동 재생이 실패할 수 있습니다. 이 경우 시작 상태로 auto 이벤트를 건너뛰거나 **앞에서 실행**으로 직접 확인합니다.

> **주의**: 씬 전환 커맨드로 게임이 처음부터 다시 시작되면 자동 재생은 그 시점에서 멈추고 이유를 콘솔에 출력합니다.

## 저장 시 검사

엔진이 건너뛰게 될 이벤트(필수 값 누락, 잘못된 형식)가 맵 파일에 있으면, 저장하기 전에 목록을 표시하고 저장 여부를 확인합니다. 에디터에서 입력한 값은 이 오류를 만들지 않으며, 다른 프로그램으로 수정한 파일에서만 발생합니다.
