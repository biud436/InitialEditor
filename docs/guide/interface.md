# 화면 구성

![씬 편집 화면](images/scene-editor.png)

## 기본 배치

| 위치 | 패널 | 용도 |
|---|---|---|
| 왼쪽 위 | 계층 | 열려 있는 씬의 오브젝트 목록 (그리는 순서대로) |
| 왼쪽 아래 | 프로젝트 | 프로젝트 폴더의 파일. 두 번 클릭하면 열립니다 |
| 가운데 | 문서 영역 | 씬, 맵, 스크립트, 그래프, 게임 탭 |
| 가운데 아래 | 콘솔 | 게임 출력, 오류, 에디터 메시지 |
| 오른쪽 위 | 인스펙터 | 선택한 오브젝트의 속성 |
| 오른쪽 아래 | 확장 패널 | RPG 이벤트처럼 확장 기능이 추가하는 패널 |

맵을 열면 팔레트, 레이어, 맵 오브젝트 패널이 자동으로 함께 열립니다.

## 패널 옮기기와 레이아웃

- 패널 탭을 원하는 곳으로 드래그하면 패널이 그 자리로 옮겨집니다. 문서 탭도 같은 방법으로 화면을 나눠 나란히 볼 수 있습니다.
- 닫은 패널은 **창** 메뉴에서 다시 열 수 있습니다.
- **창 > 레이아웃**에서 작업에 맞는 배치를 고를 수 있습니다.

| 레이아웃 | 용도 |
|---|---|
| 씬 | 기본 배치입니다. 계층, 프로젝트, 인스펙터, 확장 패널, 콘솔 |
| 스크립트 | 프로젝트와 콘솔만 남기고 편집기를 넓게 씁니다 |
| 타일맵 | 계층, 프로젝트, 맵 오브젝트, 팔레트, 인스펙터, 레이어, 콘솔. RPG 프로젝트라면 이벤트 패널도 열립니다 |

- 배치가 엉망이 되었다면 **창 > 레이아웃 초기화**를 선택하세요.
- 패널 배치와 열어 둔 탭은 프로젝트마다 저장되어, 다음에 열면 그대로 돌아옵니다.

## 도구 모음

화면 위쪽 도구 모음에는 **실행**, **정지**, **리로드** 버튼과 실행 상태가 있습니다. 오른쪽에서는 실행할 언어(Lua, Ruby)와 시작 씬을 바꿀 수 있습니다. 여기서 바꾼 값은 `game.json`의 `script`와 `startScene`에 저장됩니다.

## 상태 바

맨 아래 상태 바에는 프로젝트 경로, 실행 환경(데스크톱 앱, 브라우저 폴더 등), 게임 언어, 저장 상태, 엔진, 언어 서버, 테마가 표시됩니다. 저장하지 않은 파일이 있으면 그 개수가 나오고, 언어 서버 상태는 해당 언어의 스크립트를 열었을 때 나타납니다.

## 콘솔

- 게임의 `print` 출력, 엔진 로그, 에디터 메시지가 시간 순서대로 쌓입니다.
- `파일:줄` 모양의 오류 줄은 링크입니다. 클릭하면 해당 스크립트의 그 줄로 바로 이동합니다.
- 위쪽의 필터 입력란, 수준 목록(모든 수준, 디버그, 정보, 경고, 오류), **엔진만** 체크로 원하는 줄만 볼 수 있습니다. **지우기**를 누르면 목록이 비워집니다.

## 설정

**도구 > 설정**(Ctrl+,)에서 바꿀 수 있습니다.

| 항목 | 설명 |
|---|---|
| 테마 | 시스템 설정 사용, 다크, 라이트 |
| 실행 방식 | 프로세스(엔진 실행 파일을 별도 창으로) 또는 게임 탭(웹 엔진). 자세한 내용은 [게임 실행](running.md) |
| 엔진 경로 | 직접 지정할 엔진 실행 파일. 비워 두면 알아서 찾습니다 |
| 저장 시 리로드 | 저장하면 실행 중인 게임에 바로 적용합니다 (기본값: 켜짐) |
| 에디터 폰트 크기, 탭 크기 | 스크립트 편집기의 글자 크기와 들여쓰기 너비 |
| 에디터 표시 | 자동 줄바꿈, 미니맵 |
| 언어 서버 | 스크립트에 언어 서버를 사용합니다 (기본값: 켜짐) |
| 진단 표시 | 표시 안 함, 구문 오류만, 규칙 전체(`.luarc.json`) |
| 엔진 저장소 | 안드로이드 스테이징에 쓸 엔진 저장소 폴더 |

## 메뉴 한눈에 보기

| 메뉴 | 주요 항목 |
|---|---|
| 파일 | 새 프로젝트, 프로젝트 열기, 최근 프로젝트, 새 스크립트, 새 그래프 컴포넌트, 저장, 모두 저장, 프로젝트 닫기 |
| 편집 | 되돌리기, 다시 실행, 잘라내기, 복사, 붙여넣기, 복제, 삭제, 찾기, 프로젝트에서 찾기 |
| 씬 | 새 씬, 오브젝트 추가, 시작 씬으로 지정, 격자 표시, 스냅, 줌 |
| 맵 | 새 맵, 크기 바꾸기, 오버레이, 이 맵에서 실행, 이벤트 도구 |
| 실행 | 실행, 정지, 다시 시작, 현재 씬부터 실행, 리로드, 언어, 엔진 경로, 안드로이드로 스테이징 |
| 도구 | 설정, 언어 서버 다시 시작 |
| 창 | 패널 열기, 레이아웃, 레이아웃 초기화 |
| 도움말 | 사용자 가이드, 단축키, 엔진 API 레퍼런스, 정보 |

편집 메뉴의 복사, 붙여넣기, 복제, 삭제는 지금 보고 있는 탭에 따라 대상이 달라집니다. 씬 탭에서는 씬 오브젝트, 맵 탭에서는 맵 오브젝트, 스크립트 탭에서는 텍스트가 대상입니다.
