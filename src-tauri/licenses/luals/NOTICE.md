# LuaLS 에 함께 든 구성 요소

앱에 든 언어 서버 LuaLS(lua-language-server, MIT)의 실행 파일은 아래 구성 요소를 정적으로 묶어 만든 것이다.
LuaLS 자신의 라이선스는 같은 폴더의 `LICENSE` 다 (scripts/fetch-luals.mjs 가 배포본의 것을 복사한다). 판과 커밋은 LuaLS 3.19.1 의 서브모듈이다.
bee.lua 안의 fmt 는 MIT 에 실행 파일로 묶은 부분의 고지를 면제하는 예외가 붙어 있어 싣지 않는다.
